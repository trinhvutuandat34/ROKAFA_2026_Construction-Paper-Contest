## 1. 수준 향상 재학습(B1) 결과

설계와 판정 기준은 학습 전에 `paper/수준향상_사전기준.md`로 커밋했다. 자동 생성 결과는 `paper/results_level.md`.

| 지표 | 본실험 학습 기반(300세대, 20개) | 수준 향상 모델(1,000세대, 5개) |
|---|---|---|
| 학습 상대(BT-v2) 점수 | 0.687 | 0.598 (0.398–0.740) |
| 보류 상대(BT-v3) 점수 | 0.746 | 0.969 (0.945–0.998), BTO 학습 영향 포함 |
| 보류 학습 모델 2개 상대 점수 | 0.524 | 0.542 (0.500–0.569) |
| 전원 대전 점수(31개 모델) | 0.472–0.568 | 0.569–0.609 (1–5위) |
| 승리 중 격추승 비율 | 0.15 | 0.68 |
| D\* 95% / 90% / F(4) | 중앙값 6 / 평균 3.1 / 0.929 | 모두 17 / 평균 10.2 / 0.847 |

* 사전 판정: **높은 수준에 도달**(T1 5/5, T2 5/5, T3 5/5). 보류 상대 보조 점검 4/5.
* 해석상 주의: T1(BT-v3 점수)은 BT-v3와 트리 구조가 같은 BTO를 학습 상대로 쓴 영향으로 과대평가된다.
  학습 풀 밖의 학습 모델 상대 우위는 작다(0.542 대 0.524). BT-v2 상대 점수는 오히려 낮다.
* 설명 비용은 크게 커졌다. 수준 향상 모델 안에서도 세대–D\*90 ρ = 0.64, 점수–D\*90 ρ = 0.29(p = 0.04).
* 본실험 282개 조건에 더해 다시 검정하면 전체 연관성(−0.14–0.03)과 깊이 6 제약 비용(≈0)은 그대로다.
  깊이 6으로 재현되는 학습 시드 9의 100세대 모델(상대 2종 평균 0.846)이 수준 향상 최고 모델(0.850)과 비슷하기 때문이다.
* 학습 상대·교전 규칙·학습량을 함께 바꿨으므로 D\* 증가의 원인(성능 대 전술)은 가를 수 없다.
