## 0. 한 문단 요약 (초록 초안 재료)

* **문제.** 공중전 AI 는 성능이 높을수록 사람이 이해하기 어려워진다는 통념이 있으나,
  같은 환경·같은 잣대로 이를 측정한 연구가 드물다.
* **방법.** 1대1 기총 도그파이트 시뮬레이터에서 규칙 기반(행동트리 3종)·학습 기반
  (진화전략으로 학습한 신경망)·혼합(혼합계수 α) 정책을 **동일 관측·동일 지령공간**에서
  비교했다. 설명가능성은 행동 로그에 결정트리 대리모델을 적합해 목표 충실도에
  필요한 **최소 깊이 D\***로 정량화했고, 규칙 준수는 하드덱·과G·최소이격 위반율로 쟀다.
* **결과 (2026-09-15 본실험, 282조건·112,800교전·학습 시드 20 + 확장 분석).**
  성능과 D\* 사이에 **트레이드오프가 없다**(전체 ρ=−0.02, p=0.75; 학습·혼합만
  ρ=−0.18, p=0.006 으로 오히려 약한 음). 동등성 검정으로 |ρ| < 0.2 지지, 감쇠 보정
  후 −0.02, 시드 임의효과 모형에서 D\* 계수 p=0.82. 공통 상태 D\* 로 재면 +0.19 이고
  방문 범위를 통제해도 +0.16(동등성 불성립, results_dstar_validity.md R9a). 시드 3 → 5 → 8 → 20 에서 ρ 는 +0.38 → +0.06 → −0.16 →
  −0.02 로 움직였다 — 반복 수의 교훈. 학습 예산에 따라 순수 학습 정책의 점수는 단조
  상승(ρ=0.45, p=0.0003; 복제본 0.639 → 300세대 0.716±0.051, BT-v2 0.671, 17/20 이
  초과)하고 위반율은 감소(0.096 → 0.050)했지만, 자기 로그 D\* 는 복제본(2)을 떠나는
  순간 7 로 뛴 뒤 300세대까지 평평한 **계단 모양**이었다(25세대 간격 12시드: 초기 7.8
  대 후기 8.4, p=0.73). 공통 상태 D\* 만 10 → 16 으로 완만히 오른다. 8시드 시점의
  '산 모양'은 세밀 해상도에서 재현되지 않아 철회. 혼합은 두 형태 모두 절충점이
  아니다: 선형 혼합은 D\* 14–16, 감독형 혼합(Shield)은 위반 0 이지만 점수 0.543·
  D\* 12. 같은 예산으로 상수를 최적화한 BT(BTO)는 D\* 3–5 로 가장 단순하고 보류
  상대에 가장 강하지만(0.88) BT-v2 에 진다(0.32). 밑바닥 PPO 는 ES 와 같이 회피로
  수렴(0.385, WEZ 0초). **학습 정책의 성능 우위는 120 s·HP 규칙에 의존한다**: 240 s
  또는 시간종료=무승부에서는 BT-v2 가 앞선다. 성능–D\* 무상관은 규칙과 무관.
* **같은 예산, 다른 전술.** 300세대 순수 학습 정책 20개는 점수 0.597–0.785 이지만
  전술이 갈렸다: 16개는 한 번 스치듯 쏘고 이탈해 시간종료 HP 우위로 이기는 '치고
  빠지기'(D\* 중앙값 5), 4개는 끝까지 붙는 '추격 격추'(격추 26–35%, D\* 8–17).
  가우시안 혼합모형(BIC) 군집이 D\* 를 유의하게 가르고(Kruskal–Wallis p<0.0001)
  군집 안에서는 점수–D\* 상관이 없다. 설명가능성 차이는 성능이 아니라 **전술의
  종류**에서 왔다. 논의 절의 핵심 문단. README 6.4 표.
* **용어.** 여기서 설명가능성은 "모델 내부를 읽을 수 있는가"(내재적)가 아니라
  "행동을 몇 단계 규칙으로 재현할 수 있는가"(행동 수준)이다. 전자로는 BT 가 정의상
  이기므로 비교가 성립하지 않는다. 초록과 서론에서 이 구분을 한 문장으로 명시.
* **의의.** 세 계열(+통제 조건 셋)을 같은 잣대로 놓고 관계의 **형태**를 보였다:
  트레이드오프는 관측되지 않았고, 설명 비용은 성능이 아니라 규칙 복제본을 떠났는가와
  전술 유형에 좌우된다. 절대 순위가 아니라 관계의 형태가 기여이다.

## 1. 서론 (1쪽)

1. 배경: 공중전 AI(AlphaDogfight 등) 의 성능 향상과 군 운용상 설명·검증 요구.
2. 문제 제기: "설명 가능한 모델은 약하고, 강한 모델은 설명 불가"라는 통념은
   측정된 사실인가, 인상인가. **서론 첫 문단은 독자의 상식에서 출발할 것**(README
   0.0절): 규칙 기반은 읽을 수 있으나 약하다(H1), 학습 기반은 강하나 블랙박스다
   (H2), 혼합은 그 사이일 것이다(H3). 이 세 줄을 가설로 세운 뒤, 왜 그대로는 잴
   수 없는지(아래 내재적/행동 수준 구분)를 이어서 쓴다. 결과·결론에서는 H1–H3
   각각의 판정(README 0.0절 표)을 되돌아본다 — 독자가 논문의 줄거리를 잃지 않게
   하는 장치.
   * 이 통념은 설명가능성을 **내재적**(트리·규칙 = 설명 가능, 신경망 = 블랙박스)
     으로 볼 때 동어반복이 된다: 계열이 곧 설명가능성이므로 남는 것은 성능 비교뿐이고,
     "BT 가 약하다"는 결과가 자동으로 트레이드오프로 읽힌다.
   * 본 연구는 설명가능성을 **행동 수준**으로 정의한다: 정책이 무엇으로 만들어졌든
     그 행동을 몇 단계짜리 규칙으로 재현할 수 있는가(D\*). 이 잣대는 세 계열에
     똑같이 적용되므로 BT 도 표본에 들어가고, "상관 없음"은 이 잣대에 대한 진술이다.
     서론에서 이 구분을 **반드시 한 문단**으로 — 심사위원이 가장 먼저 물을 지점.
3. 연구 질문 세 가지
   * RQ1. 규칙 기반·학습 기반·혼합 모델의 전투성능과 설명가능성 사이에 어떤 관계가 있는가?
   * RQ2. 학습 예산(학습량)이 늘어날 때 두 축은 어떻게 함께 움직이는가?
   * RQ3. 규칙 준수(안전 제약)는 이 관계에서 어떤 위치에 있는가?
4. 기여 요약: (i) 세 계열에 동일 적용되는 설명가능성 지표, (ii) 진영 교대 짝지은
   평가 설계, (iii) 학습 예산과 혼합계수를 독립변수로 한 2차원 스윕.

## 2. 관련 연구 (0.5–1쪽)

* 공중전 AI: 규칙/전문가 시스템 → 강화학습(AlphaDogfight Trials, Pope et al. 2021 등).
* 설명가능 AI: 모델 내재적 설명(트리, 규칙) vs. 사후 설명(SHAP, LIME). 내재적
  설명은 계열을 고르는 순간 결정되어 계열 간 비교의 **변수가 될 수 없고**, 사후
  설명은 모델 계열 의존적이라 **계열 간 비교 잣대로 부적합** → 계열에 무관하게
  행동 로그에만 적합하는 대리모델 충실도(surrogate fidelity; Ribeiro 2016, Bastani
  2018 VIPER 등)를 채택한 근거. 대리모델 깊이는 "규칙으로 얼마나 짧게 기술되는가"
  이므로 내재적 설명가능성의 행동 수준 대응물로 위치시킬 것.
* 성능–해석가능성 트레이드오프 논쟁(Rudin 2019 "Stop explaining…" 은 트레이드오프가
  항상 존재하지는 않는다고 주장) → 본 연구는 "특정 과업에서 실측"으로 위치.
* 행동트리(BT) 의 게임/로봇 분야 활용, 하이브리드(규칙+학습) 제어.

## 3. 방법 (3쪽)

### 3.1 교전 환경
* 3자유도 점질량 F-16급 모델, 명시적 오일러 0.05 s, 제어주기 0.2 s, 교전 120 s.
* 기총 WEZ: 사거리 120–1,200 m, 명중 원추 3°→10° 선형 확대, 25 HP/s.
* 승패 규칙(격추·지면충돌·공중충돌·시간종료), 초기조건 범위.
* **표: 부록 A** (config 스냅샷). 본문에는 핵심 값만.
* 한계 선언: 받음각·실속·탄도 미모사 → "이 모델 범위 안에서 유효".

### 3.2 정책 세 계열
* 공통 인터페이스: 관측 20차원(교전기하) → 지령 3차원(뱅크·하중배수·스로틀).
  **"세 모델이 같은 관측·같은 지령공간"** 이 대리모델 비교 공정성의 근거임을 명시.
* BT 3종: BFM 교범 전술(순수/리드추격, 코너속도, 하드덱 회복, **정면 합류 회피**)만
  사용. **BT 는 학습시키지 않았고 사람이 썼다**는 문장을 명시(내재적 설명가능성의
  근거). 세 버전은 성숙도 사다리가 아니라 **서로 다른 교리**임을 밝힘. **표 M1**
  (노드 수, 트리 구조). 노드별 조건·행동·문턱값 전문은 README 3.1 — 본문에는
  BT-v3 를 "조종사 말로 읽은" 네 문장과 표를, 나머지 두 트리와 문턱값은 부록 B 로.
  대전 절차 6단계와 계열별 결과 한 표는 README 3.5 를 그대로 옮기면 방법 3.3 과
  결과 4.2 의 뼈대가 된다. 합류 회피 노드를 넣게 된 경위(충돌 45–53% → 3–10%)는
  README 9.1 — 방법 절에 한 문단으로.
* 학습 정책: MLP 20-32-32-3. **BT-v2 행동 복제로 초기화**(16만 샘플 회귀, 뱅크
  R² 0.95) 후 OpenAI-ES 변형(미러 샘플링, 순위 정규화, σ 0.05, lr 0.01, pop 32,
  후보당 8교전, **갱신 수용 검사**)으로 미세조정. 포텐셜 기반 셰이핑(Ng et al.
  1999 — 최적정책 불변). 체크포인트 0(복제본)/100/200/300 세대 = 학습 예산 축.
  α=1.0 은 MLP 만 실행하는 블랙박스라는 정의는 유지됨.
  **설계 이력을 반드시 쓸 것**: (1) 1차 적합도는 원거리 회피로 수렴(보상 해킹),
  (2) 적합도를 고쳐도 무작위 초기화에서는 여전히 회피 — 교전 시도의 기대 손실이
  회피보다 커서 ES 탐색이 실패, (3) 복제 초기화로 해결했으나 기존 ES 갱신이
  무작위 행보로 복제본을 지움, (4) 수용 검사로 해결. README 9.2–9.3 / shaping.py 상단.
  심사위원이 가장 좋아하는 종류의 정직한 기록입니다.
* 이 설정이 논문에 주는 이점: 예산 0 에서 학습 정책은 BT-v2 와 행동이 거의 같으므로
  D\* 도 비슷해야 한다(검증 가능한 예측). 예산이 늘며 성능이 갈릴 때 D\* 가 어떻게
  움직이는지가 곧 RQ2 의 답이다. "BT 는 트리라 유리"라는 반론도 같은 행동을 내는
  MLP 의 D\* 로 직접 반박된다.
* 혼합: a = (1−α)a_BT + α a_RL, α 를 관측에 포함해 정책 하나로 전 구간 커버.
  매 세대 α∈{0.25, 0.5, 0.75, 1.0} 을 한 판씩 고정(평가 격자와 동일).
* **(확장) 상수 최적화 BT(BTO).** BT-v3 와 같은 구조·노드 수(11)에 상수 9개(G 사용
  비율, 리드 게인, 사격 진입 거리·총각, 하드덱 여유, 합류 회피 거리·접근률·뱅크,
  스로틀)만 학습 정책과 **같은 적합도·같은 예산**(300세대·개체군 32·후보당 8교전·
  수용 검사)으로 진화전략 최적화. "규칙 모델이 약한 것은 손으로 만들어서다"라는
  반론(Rudin 2019)에 대한 통제 조건. 탐색 보폭만 다름(9차원 σ 0.10·lr 0.05 대
  1,827차원 σ 0.05·lr 0.01) — 명시할 것. `agents/bt_param.py`, `rl/train_es_bt.py`.
* **(확장) 감독형 혼합(Shield).** 안전 규칙(합류 회피·하드덱 회복)이 발동하면 BT-v3
  지령, 아니면 학습 정책 지령에 8 G 상한만 적용. 지령 선형 혼합이 허수아비라는
  반론에 대한 조건. `agents/shield.py`.
* **(확장) 밑바닥 PPO.** BT 복제 초기화 없이 무작위 초기화에서 PPO(SB3, 150만 스텝,
  α=1 고정, 같은 셰이핑·같은 상대)로 학습한 2시드. 실패하면 실패를 결과로 보고.
  `rl/train_ppo.py`. 학습 계열이 ES 하나라는 반론에 대한 조건.
* **(확장 2, 2026-09-29 완료) 잔차형·게이팅형 혼합.** 혼합 설계 방식 자체를 변수로:
  잔차형은 a = a_BT-v2 + β·δ(o), β=0.35 (학습이 규칙을 뒤집지 못하고 다듬기만 함),
  게이팅형은 a = (1−g(o))·a_BT-v2 + g(o)·a_RL, g 는 20-8-1 게이트 신경망이 상황마다
  결정(학습 정책은 시드 11 300세대 고정). 각 200세대·3시드. README 3.6·6.10,
  `paper/results_hyb.md`. 결과: 잔차형 0.628(BT-v2 를 넘지 못함, D\* 6/6/17), 게이팅형
  0.722(순수 학습에 근접, D\* 17/17/17, 게이트가 고정 비율로 수렴). 방법 3.2 에 한 문단,
  결과 4.15, 논의 4 에 "혼합 4종 트레이드오프 지도"로. 초안은 `paper/논문_초안.md` 3.4·4.6.2·5.4절.

### 3.3 평가 설계
* 상대: 고정 BT-v2(학습 시 사용) 와 BT-v3(**보류 상대**, 학습에 미사용).
* **진영 교대 짝지은 설계**: 같은 시드로 청/홍을 바꿔 2회. 자기대전 검증에서
  0.59 → 0.500 으로 편향 제거(README 5.1). 이 검증을 본문에 **한 문장으로** 넣을 것.
* 통계: 시드 단위 평균 → Wilson CI, 대응표본 Wilcoxon, Holm 보정, 이항검정.
* **(확장) 학습 시드 20개**(0–19). 시드 8–19 는 25세대 간격 체크포인트로 예산–D\*
  형태 검증(results/dense) — 결과는 계단 모양. 상관의 표본 독립성 문제는 학습 시드 임의효과 혼합모형과
  시드 클러스터 부트스트랩으로 다룸(`analysis/robustness.py`, results_ext.md R2·R4).
* **(확장) 정책 풀 상호 대전.** 학습 정책 20개 + BT 3종 + BTO 로 전원 대전, 풀 평균
  점수를 제2의 성능 지표로(results_ext.md R8).
* **(확장) 환경 규칙 민감도.** 제한시간 240 s, 시간종료=무승부 규칙으로 재평가
  (results_ext.md R7).

### 3.4 세 평가축
* 성능: 점수(승1/무0.5/패0) **와** 무승부 제외 순수승률 둘 다.
* 설명가능성: D\*(0.95) 주지표, D\*(0.90/0.99)·F(4) 보조. **절단(17) 명시.**
  분산가중 평균, 상수 채널 처리, 행동 포화 함정(README 4.2)을 한 문단으로.
  * **(확장) 공통 상태 D\*.** 모든 조건의 로그를 합쳐 균일 추출한 관측 40,000개를 각
    정책에 똑같이 질의해 적합한 D\*_common. 자기 로그 D\* 가 "상황의 다양성"을 재는
    것 아니냐는 교란을 분리(results_ext.md R3). 상태 방문 범위(3차원 히스토그램
    엔트로피)를 공변량으로 편상관(공통 상태 D\* 기준 편상관은 results_dstar_validity.md R9a).
  * **(확장) 신뢰도.** 반분(전반/후반 교전) D\* 의 Spearman–Brown 신뢰도, 점수의
    홀짝 시드 신뢰도, 감쇠 보정 상관(R1). "상관 없음"이 잡음 때문이 아님을 보이는 표.
  * **(확장) 동등성 검정.** ρ 의 부트스트랩 90% CI 가 ±0.2 안에 들어오면 "상관이
    0.2 보다 작다"를 α=0.05 로 주장(TOST, R2). '유의하지 않다'와 '작다'를 구분.
  * **(확장) 사람 기반 평가.** 설계·문항은 준비됨(paper/사람평가_프로토콜.md), **미실시**.
    한계 절에 그대로 씀.
* 규칙 준수: 스텝당 위반율(하드덱 1,000 m·8 G·150 m).

## 5. 논의 (2–3쪽)

1. **RQ1 답**: 상관 없음(ρ=−0.02, n=282; 학습·혼합만 −0.18; TOST 로 |ρ|<0.2). 규칙
   모델(D\* 1–5)과 학습 정책(3–17)의 범위가 겹친다. 공통 상태 D\* 로는 +0.19,
   방문 범위 통제 후 +0.16 — 자기 로그 D\* 에서는 무상관, 공통 상태 D\* 에서는 작은 양의 상관이라고 구분해 쓴다. BT-v2 가 노드 5개인데 D\*=4 인 이유(연속 arctan2 함수)와, 그것을 복제한
   MLP 가 D\*=2 인 사실을 "트리 구조가 유리한 것이 아니다"의 근거로.
   3 → 5 → 8 → 20시드에서 ρ 가 +0.38 → −0.02 로 간 것을 반복 수의 교훈으로 한 문단.
2. **RQ2 답**: 예산이 늘수록 성능은 단조 상승, 위반은 감소, 자기 로그 D\* 는 복제본을
   떠나는 순간 뛰고 평평(계단), 공통 상태 D\* 는 완만히 상승. "학습할수록 블랙박스가
   된다"는 자기가 가는 상황에서는 틀리고 안 가는 상황까지 물으면 맞다. 같은 예산·
   비슷한 점수에서 전술(치고 빠지기 16 vs 추격 격추 4)에 따라 D\* 가 3–17 로 갈리고
   군집 안에서는 상관이 없다(R5) — 설명 비용의 진짜 원인. 부록 F(격추 우선 적합도)와
   R7(규칙 민감도)로 이 전술이 적합도·규칙의 산물인지 확인한 결과를 붙임: 적합도의
   산물은 아니고, 성능 우위는 규칙(120 s·HP)에 의존.
3. **RQ3 답**: BT-v3·Shield 처럼 규칙을 명시하면 위반율 0 이 보장되지만 성능을
   내준다(0.329, 0.543). 학습 정책은 셰이핑 벌점만으로 위반율을 BT-v2 의 절반으로
   낮추면서 성능도 올렸지만 0 은 아니다. D\*–위반율 ρ=0.29: 규칙을 어기는 정책은
   규칙으로 설명하기도 어렵다. "보장 vs 낮은 기대값"이라는 운용 선택 기준.
4. **혼합 다이얼의 위치**: 파레토 프론티어 아래. 선형 혼합은 성능에서 순수 학습 정책을
   넘지 못하고(α=0.75 가 근접) 설명가능성은 어느 쪽보다 나쁘다(D\* 14–16). 감독형
   혼합(Shield)도 위반 0 을 얻는 대신 점수 0.543·D\* 12 로 두 축을 내준다. "혼합은
   두 형태 모두 절충점이 아니다"로 정직하게. **확장 2 결과: 잔차형·게이팅형도 절충점이
   아니었다.** 잔차형은 BT-v2 를 넘지 못한 채 D\* 4 → 6–17, 게이팅형은 성능은 순수 학습에
   근접했지만 D\* 3·4 인 두 정책을 섞은 결과가 17. "설명하기 쉬운 두 정책을 섞으면 설명하기
   어려운 정책이 된다"를 논의의 핵심 문장으로.
5. **반론 선제 대응**
   * "설명가능성이란 결국 BT 냐 신경망이냐 아닌가" → 그것은 내재적 설명가능성.
     본 연구는 행동 수준 설명가능성을 재며, 내재적 잣대로는 비교가 성립하지 않는다
     (서론 2). 같은 BT 라도 행동이 복잡하면 D\* 가 크다(BT-v2 D\*=4, BT-v3 D\*=5).
   * "BT 는 원래 트리라 유리" → 대리모델은 행동에만 적합, 동일 관측·지령공간, BT-v2 반례.
   * "D\* 는 트리에 유리한 지표" → F(4), D\*(0.90/0.99) 로 강건성, 절단 명시.
   * "BT 와 RL 에 들인 노력이 다르다" → **개발노력_기록.md** 수치 인용. 절대 순위가
     아니라 관계 형태가 주장임을 재확인.
   * "ES 는 RL 이 아니다" → 학습 기반 블랙박스 정책이라는 점이 논지의 핵심이며,
     알고리즘 명시. 밑바닥 PPO 결과(표 1 PPO 행)를 함께 제시.
   * "D\* 가 시끄러워 상관이 0 으로 감쇠된 것" → R1 신뢰도·감쇠 보정 상관.
   * "유의하지 않다 ≠ 없다" → R2 동등성 검정.
   * "D\* 는 상황 다양성을 잰다" → R3 공통 상태 D\*·편상관.
   * "67개(→약 270개) 조건은 독립이 아니다" → R4 혼합모형·클러스터 부트스트랩.
   * "규칙 모델이 약한 건 손으로 만들어서" → 같은 예산으로 최적화한 BTO 도 BT-v2 에
     진다(0.32). 단 보류 상대에는 가장 강함(0.88).
   * "혼합이 나쁜 건 선형 혼합이라서" → Shield 도 점수·D\* 를 함께 내줌.
   * "전술 이름은 사후 명명" → R5 군집.
   * "산 모양은 표준편차 안" → 맞다. R6 에서 재현되지 않아 철회하고 계단으로 보고.
   * "결과는 120 s·HP 규칙의 산물" → 성능 순위는 그렇다(R7: 240 s·무승부 규칙에서 BT-v2 가
     앞섬). 성능–D\* 무상관은 규칙과 무관. 결론 2 에 단서로 명시.
   * "성능 = BT-v2 이기기" → R8 정책 풀.
