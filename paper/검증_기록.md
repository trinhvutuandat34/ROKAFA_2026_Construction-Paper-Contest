## 3. 초안의 표현이 근거보다 강한 곳 (수치는 고치지 않고 표현만 조정 또는 저자 판단으로 남김)

1. **"자기 로그 D\*" 와 "공통 상태 D\*" 가 다른 이야기를 한다.** 자기 로그 D\* 의 중앙값은 BT 4, BTO 3, 학습 정책 6 이라 학습 정책이 규칙 모델과 비슷해 보이지만,
   공통 상태 D\* 는 BT 5, BTO 4, 학습 정책 17 이다. 정책이 가지 않는 상황까지 물으면 학습 정책이 훨씬 예측하기 어렵다. 초안 5.2 는 이 점을 RQ2 에서만 쓰고,
   표 12 의 H2 판정("설명 쪽은 기각")과 초록·결론은 자기 로그 D\* 만 근거로 삼고 있었다. 표 12 에 기준을 명시했다. **어느 잣대를 대표 지표로 삼을지는 저자가 정할 문제다.**
2. **절단(D\*=17)은 "16단계로도 설명되지 않는다"가 아니다.** 절단은 R²(0.95) 미달이고, 절단 조건 163개의 F(16) 중앙값은 0.924, F(16) ≥ 0.94 가 23개다
   (`results_dstar_validity.md` R9c). 초록·5.4·결론의 "16단계 규칙으로도 설명되지 않았다"는 "R² 0.95 에 도달하지 못했다"로 바꾸는 편이 정확하다.
3. **D\* 는 문턱 통계량이다.** F(d) 곡선이 깊이에 대해 단조가 아닌 조건이 282개 중 278개이고, 절단이 아닌 119개 중 73개는 D\* 에서의 F 가 0.955 미만이다.
   그래도 "점수–D\* 상관 없음"은 임계값을 0.90–0.97 로 바꾸거나 문턱 없는 F(4)·평균 F 로 바꿔도 유지된다(R9b). 임계값 0.98(절단 91%)에서만 ρ=+0.21 로 뒤집힌다.
4. **교전 단위 분할에서 학습 정책의 D\* 가 올라간다.** 같은 실행 안에서 비교하면 학습 정책 61개의 D\* 중앙값은 무작위 스텝 분할 6, 교전 단위 분할 9 이고 F(16) 평균은 0.963 에서 0.939 로 내려간다.
   규칙 모델(BT 3종·BTO)은 거의 변하지 않는다(중앙값 3–4). 스텝 단위 분할은 이웃 스텝이 훈련·시험 양쪽에 들어가 학습 정책의 충실도를 후하게 준다는 뜻이다. 성능과의 상관은 그대로지만(ρ=+0.01),
   "학습 정책의 자기 로그 D\* 가 규칙 모델과 비슷하다"는 문장은 분할 방식에 따라 폭이 달라진다(R9d). 대표 지표를 정할 때 함께 고려할 것.
5. **R4 의 D\* 단독 모형은 유의하다.** 초안은 전체 모형의 D\* 계수(p=0.82)만 썼다. `results_ext.md` R4 의 D\* 단독 모형은 계수 −0.014, p=0.0006 이다(점수가 낮을수록 D\* 가 큼, 즉 트레이드오프의 반대 방향).
   예산·α 를 넣으면 사라진다. 둘 다 적는 편이 안전하다.

## 4. 확인하지 못한 것

* 학습(ES·PPO)·행동 복제는 다시 돌리지 않았다. 학습 정책의 "재현성"은 저장된 체크포인트로 평가를 되풀이한 것까지다.
* torch·gymnasium·stable-baselines3 가 필요한 경로(`pretrain_bc.py`, `train_ppo.py`)는 실행하지 않았다.
* 전체 282조건의 D\* 를 새 환경에서 다시 적합하지 않았다(13조건만). Shield 시드 0 처럼 문턱 근처 조건은 환경에 따라 값이 바뀔 수 있다.
* 참고문헌 29건의 서지, 인용 위치의 정확성은 확인하지 않았다. 추가한 [30]–[32] 중 [31](Saldiran 외 2024)만 원문을 읽었고, [30] 은 Saldiran 참고문헌으로 날짜를 확인했으며, [32] 는 검색 요약까지다(`참고문헌_2.1_검증.md`).
* 대회 양식·분량 제한·보안성 검토 요건은 저장소에 없어 확인하지 못했다.
