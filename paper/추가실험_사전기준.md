# 추가 실험 사전 판정 기준 — 학습 모델·하이브리드 성능 수준 보강 (2026-10-08)

이 문서는 학습과 평가를 시작하기 전에 작성하였다. 판정 기준은 결과를 본 뒤 바꾸지 않는다.
6자유도 교차검증(`6DOF_교차검증_사전기준_초안.md`)과 같은 방식이다.

## 0. 왜 하는가

검토 문서 「학습 모델·하이브리드의 성능 수준 검토」(2026-10-08)의 지적: 심사에서 "학습 모델이 약해서
트레이드오프가 보이지 않은 것 아니냐"는 반박이 나오면 결론이 흔들린다. 근거는 다음과 같다.

* 보류 상대(BT-v3) 기준으로 300세대 학습 모델 20개 가운데 BT-v2(0.843)를 넘은 모델이 없고 최고 모델은 BTO(0.882)이다.
* 우위의 원천이 120초 제한·시간종료 체력 비교 규칙에 기댄 '치고 빠지기'(16/20)이다.
* 학습 규모가 시드당 약 7만 7천 교전이고, 125세대 이후 점수가 0.03 정도만 올랐다.
* 잔차형·게이팅형 하이브리드는 3시드·200세대로 본실험보다 덜 학습되었다.

따라서 다음 세 실험(검토 문서 5.1–5.3)을 한다.

## 1. 공통 평가 절차 (본실험과 동일)

* 상대 BT-v2(학습 상대)·BT-v3(보류 상대), 평가 초기조건 10000–10099의 100개 × 진영 교대 2 = 상대당 200교전, 모델당 400교전.
* 점수: 승 1, 무 0.5, 패 0의 평균. 상대 2종 평균을 보조로 쓴다.
* 설명 비용: 상대별 초기조건 30개의 청군 교전 기록으로 대리 결정트리를 적합(70/30 분할), D\*(95%, 주 지표), D\*(90%), F(4).
* 종료 사유(격추·시간종료·충돌 비율), WEZ 체류 시간, 위반율.
* 평가 코드는 `dfxai.experiments.run_eval`과 `dfxai.analysis.report`를 고치지 않고 그대로 쓴다.
  이 환경에서 300세대 학습 시드 1·11 모델을 다시 평가하면 본실험의 교전 결과가 교전 단위까지 같았다(800교전 전부 일치).

## 2. E1 — 학습 연장 (검토 문서 5.1, 최우선)

**설계.** 학습 시드 1, 11, 14, 2, 18의 5개를 300세대 체크포인트에서 1,000세대까지 이어 학습한다.
설정은 본실험과 같다(개체군 32, 후보당 8교전, σ 0.05, lr 0.01, 상대 BT-v1·BT-v2 교대, α 격자, 수용 검사).
이어 학습은 가중치·보폭·수용 횟수를 이전 기록에서 복원하고 난수열을 300세대만큼 되감으므로, 같은 기계에서는 처음부터
1,000세대를 돌린 것과 같은 계산이다(`train_es.py --resume`, 같은 기계에서 끊었다 이은 학습과 끊지 않은 학습의
적합도와 가중치가 비트 단위로 일치함을 확인). 기계가 바뀌면 부동소수점 차이로 적합도가 소수점 넷째 자리에서 달라지므로,
본실험 300세대와 "같은 궤적"은 아니고 "같은 설정의 연장"이다.

시드 선정 이유(300세대 상대 2종 평균 점수 / D\* / 전술 군집):

| 시드 | 점수 | D\* 95% | 군집 | 선정 이유 |
|---|---|---|---|---|
| 1 | 0.785 | 17 | 추격 격추 | 점수 1위 |
| 11 | 0.776 | 3 | 치고 빠지기 | 점수 2위, 게이팅형의 원 모델 |
| 14 | 0.704 | 11 | 추격 격추 | 중위, 추격 격추 |
| 2 | 0.746 | 6 | 치고 빠지기 | 중위, 치고 빠지기 |
| 18 | 0.598 | 9 | 치고 빠지기 | 최하위 |

**평가.** 300, 400, …, 1,000세대(시드당 8개, 계 40개 모델)를 1절 절차로 평가한다.

**판정.** S(g)는 상대 2종 평균 점수, ΔS = 5개 시드 평균 [S(1000) − S(300)], ΔD = 5개 시드 평균 [D\*95(1000) − D\*95(300)].

| 성능 판정 | 조건 |
|---|---|
| 정체 | ΔS < 0.03 |
| 소폭 향상 | 0.03 ≤ ΔS < 0.05, 또는 ΔS ≥ 0.05이지만 5개 중 4개 미만의 시드에서 향상 |
| 뚜렷한 향상 | ΔS ≥ 0.05이고 5개 중 4개 이상의 시드에서 S(1000) > S(300) |

| 설명 비용 판정 | 조건 |
|---|---|
| 증가 | ΔD ≥ 2이고, 300–1,000세대 40개 점에서 세대와 D\*95의 Spearman ρ > 0, p < 0.05 |
| 증가 없음 | 그 밖 |

| 조합 | 원고에 쓸 결론 |
|---|---|
| 정체·소폭 향상 + 증가 없음 | 추가 학습의 이득이 작은 상태에서 측정하였고 설명 비용은 커지지 않았다. "학습이 덜 돼서"라는 반박을 막는다(4.3.2, 5.6) |
| 뚜렷한 향상 + 증가 없음 | 더 높은 성능에서도 설명 비용이 커지지 않았다. 검증 범위가 넓어진다 |
| 뚜렷한 향상 + 증가 | 고성능 영역에서 트레이드오프가 나타난다. 결론을 "성능 범위에 따라 달라진다"로 고친다 |
| 정체 + 증가 | 성능과 무관하게 설명 비용만 커졌다. 4.3.2의 "학습량이 늘어도 D\*는 커지지 않음"을 고친다 |

보조 보고(판정에 쓰지 않음): 시드별 BT-v2·BT-v3 점수 곡선, 1,000세대 모델 가운데 BT-v3 상대 점수가 BT-v2(0.843)나
BTO(0.882)를 넘는 모델의 수, 종료 사유의 변화(치고 빠지기가 추격 격추로 바뀌는가), D\*90과 F(4).

## 3. E2 — 하이브리드 보강 (검토 문서 5.2)

**설계.** 잔차형(β 0.35)·게이팅형(학습 시드 11의 300세대 모델 고정)을 각각 시드 5개(0–4), 300세대로 늘린다.
시드 0–2는 200세대 체크포인트에서 이어 학습하고(`train_es_hybrid.py --resume`), 시드 3–4는 새로 300세대를 학습한다.
설정은 확장 실험과 같다(개체군 32, 후보당 8교전, σ 0.05, lr 0.01).

**평가.** 100, 200, 300세대(방식당 15개 모델)를 1절 절차로 평가한다. 원 모델(BT-v2, 학습 시드 11 300세대)을 같은 실행에 넣는다.

**판정.** 본 원고 4.4절의 기준을 그대로 쓴다. 하이브리드가 두 원 모델 가운데 하나를 **두 축에서 동시에 앞서면**
(상대 2종 평균 점수가 높고, 초기조건 단위 Wilcoxon 부호순위 검정 p < 0.05, 그리고 D\*95가 그 원 모델 이하) 절충점으로 본다.
5개 시드 중 3개 이상이 절충점이면 그 방식은 "절충점이 될 수 있다"로 판정을 바꾼다. 아니면 기존 판정을 5시드·300세대에서 유지한다.

보조 보고: 300세대 점수가 200세대보다 오르는가(시드 0–2), 원 모델 대비 점수 차의 5시드 평균과 범위,
게이트 값의 교전 안 표준편차(게이팅형), |δ| 평균(잔차형).

## 4. E3 — "격추만 승리" 규칙 재학습 (검토 문서 5.3)

**설계.** 학습 환경의 시간종료 규칙을 무승부로 바꾸고(`train_es.py --timeout-rule draw`) 그 밖의 설정은 본실험과 같게 두어
학습 시드 0–4를 복제본에서 300세대 학습한다. 적합도 식은 바꾸지 않는다(시간종료가 무승부가 되므로 시간종료승 +5가 사라진다).

**평가.** 100, 200, 300세대를 같은 무승부 규칙에서 평가하고(4.5.1절의 재평가와 같은 규칙), 300세대는 본실험 규칙(체력 비교)에서도 평가한다.

**비교 기준(무승부 규칙 재평가, `results/sens_draw`).** 본실험 300세대 학습 모델 20개 평균 BT-v2 0.498 · BT-v3 0.559,
BT-v2의 BT-v3 상대 0.792, BTO 3개 BT-v2 0.39 · BT-v3 0.82.

**판정.**

| 판정 | 조건 |
|---|---|
| 규칙 허점 없이도 학습 상대를 이긴다 | 5개 중 3개 이상의 시드가 무승부 규칙에서 BT-v2 상대 점수 > 0.5 (승·패만 남긴 이항 검정, Holm 보정 p < 0.05) |
| 그렇지 않다 | 그 밖 |

D\*는 판정에 쓰지 않고 본실험 300세대 20개의 분포(중앙값 6, 범위 3–17)와 나란히 보고한다.
재학습 모델의 군집(종료 사유)이 '추격 격추'로 옮겨 가는지도 보고한다.

## 4-1. E4 — 학습 규모 확대 (추가, E1 결과를 보기 전에 기록)

**왜.** E1은 세대 수만 늘린다. 검토 문서 2.1절의 "학습 규모가 알파독파이트급과 차이가 크다"는 지적에는
세대당 표본 수(기울기 추정의 잡음)도 포함된다. 학습 모델의 수준을 실제로 끌어올릴 수 있는지를 직접 시험한다.

**설계.** 개체군 32 → 64, 후보당 교전 8 → 16(세대당 교전 수 4배), 그 밖의 설정은 본실험과 같다.
복제본에서 시작해 학습 시드 0, 1, 2를 300세대 학습한다(`results/es_big`). 시드당 약 31만 교전으로 본실험의 4배다.

**평가.** 100, 200, 300세대를 1절 절차로 평가한다(`results/extra_big`).

**판정.** 비교 기준은 본실험 300세대 학습 모델 20개(상대 2종 평균 0.716, BT-v2 0.687, BT-v3 0.746, D\*95 중앙값 6).

| 성능 판정 | 조건 |
|---|---|
| 규모 확대로 성능이 오른다 | 300세대 3개 시드의 상대 2종 평균 점수 평균이 0.766(기준 + 0.05) 이상이고, 3개 모두 기준 평균(0.716)보다 높다 |
| 오르지 않는다 | 3개 시드 평균이 0.736(기준 + 0.02) 미만 |
| 소폭 | 그 사이 |

설명 비용은 3개 시드의 D\*95를 본실험 20개의 분포(중앙값 6, 사분위 범위)와 나란히 보고한다. 성능이 오르고
3개 시드의 D\*95가 모두 본실험 20개의 상위 사분위(9) 이상이면 "고성능 영역에서 설명 비용이 커질 가능성"으로 보고한다.

> **2026-10-08 갱신(실행 전 취소).** 검토 문서가 6절(수준 향상 실험 계획)을 최우선으로 갱신함에 따라 E4는 실행하지 않고,
> 기본안 B1(상대 풀 + 격추만 승리 + 1,000세대) 위에서 규모를 키우는 B2로 대체한다(`수준향상_사전기준.md`). E1은 낮은 우선순위로 계속하고 E2·E3는 B1 뒤로 미룬다.
