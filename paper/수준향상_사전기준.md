# 학습 모델 수준 향상 실험 — 목표 기준과 설계 (2026-10-08, 학습 전 기록)

검토 문서 「학습 모델·하이브리드의 성능 수준 검토」 6절(수준 향상 실험 계획, 최우선)을 실행하기 위한 사전 기록이다.
판정 기준은 결과를 본 뒤 바꾸지 않는다. 방어용 추가 실험(E1–E3)의 기준은 `추가실험_사전기준.md`에 있다.

## 1. "높은 수준"의 정의 (검토 문서 6.1)

학습 상대(BT-v2)를 직접 이기는 점수는 목표로 삼지 않는다. 판정 시점은 **1,000세대 체크포인트**로 미리 정한다.
평가는 본실험과 같은 절차(상대 BT-v2·BT-v3, 평가 초기조건 10000–10099 × 진영 교대, 상대당 200교전)이고
**본실험 규칙(시간종료 체력 비교)**에서 잰 값으로 판정한다. 무승부 규칙 값은 함께 보고한다.

| 기준 | 지표 | 충족 | 부분 충족 | 현재(본실험 300세대 20개) |
|---|---|---|---|---|
| T1 일반 교전 능력 | 보류 상대(BT-v3) 점수 | 5개 시드 중 2개 이상이 0.882(BTO 평균) 초과 | 1개만 0.882 초과, 또는 2개 이상이 0.843(BT-v2) 초과 | 최고 0.838, 평균 0.746 |
| T2 상대적 우열 | 전원 대전 점수 | 새 모델 5개 모두가 행동트리 3종·BTO 3개의 최고값보다 높음 | 3–4개 | 학습 모델 0.48–0.58 대 BT-v2 0.43 |
| T3 규칙 허점 의존 | 승리 가운데 격추승 비율 | 5개 시드 중 3개 이상에서 0.5 이상 | 1–2개 | 치고 빠지기 16/20 |
| (참고) 비행역학 일반화 | 6자유도 BT-v2 상대 점수 | 0.5 이상 | – | 0.371 |

* 시드 하나의 최고값만 보면 평가 잡음(상대당 200교전, 표준오차 약 0.025)으로 운 좋은 시드가 뽑히므로 T1은 2개 이상을 요구한다.
* 전원 대전(T2)은 본실험의 26개 모델(학습 기반 300세대 20, 행동트리 3, BTO 3)에 새 모델 5개를 더한 31개 모델을
  초기조건 30개 × 진영 교대로 서로 전부 붙인다(본실험 전원 대전과 같은 절차, `dfxai.experiments.round_robin`).
* 6자유도 기준은 참고로만 보고하고 판정에 쓰지 않는다.
* **종합 판정**: T1·T2·T3가 모두 충족이면 "높은 수준에 도달", 하나라도 미충족이면 "도달하지 못함", 그 밖은 "부분 도달".

## 2. 기본안 B1 (검토 문서 6.2의 1–3을 함께 적용)

| 항목 | 본실험 | B1 |
|---|---|---|
| 초기화 | BT-v2 복제본 | 같음 |
| 학습 상대 | BT-v1·BT-v2 교대 | **상대 풀**: 세대당 8교전을 BT-v1 1, BT-v2 2, BTO 2(3개 중 무작위), 이전 학습 모델 3으로 배정 |
| 이전 학습 모델 | – | 본실험 300세대 학습 모델 20개 + 자기 체크포인트(100세대마다 추가) |
| 교전 규칙(학습) | 시간종료 체력 비교 | **격추만 승리**(시간종료 = 무승부) |
| 학습 세대 | 300 | **1,000** |
| α | 격자 {0.25, 0.5, 0.75, 1.0} | **1.0 고정**(순수 학습 정책만 학습) |
| 진화전략 | 개체군 32, 후보당 8교전, σ 0.05, lr 0.01, 수용 검사 | 같음 |
| 적합도 | 본실험 식 | 같음(시간종료가 무승부이므로 시간종료승 +5가 사라짐) |
| 학습 시드 | 0–19 | 0–4 |

* BT-v3는 학습에 쓰지 않는다(보류 상대 유지).
* **주의.** BTO는 BT-v3와 트리 구조가 같고 상수만 다르다. BTO를 학습 상대에 넣으므로 BT-v3가 구조까지 완전히
  처음 보는 상대는 아니다. 결과 해석에서 이 점을 밝힌다.
* α를 1.0으로 고정한 이유: 본실험은 선형 혼합형을 같은 신경망으로 만들려고 α 격자로 학습해 순수 정책(α = 1)의 학습
  신호가 교전의 1/4이었다. 이번 목적은 학습 모델의 수준이므로 순수 정책만 학습한다. 따라서 B1 모델로는 본실험 방식의
  선형 혼합형을 만들지 않는다.
* 실행: `bash results/run_level_train.sh b1` (`results/es_pool`). 평가: `bash results/run_level_eval.sh b1`.

## 3. B1 다음 단계 (결과에 따라)

| B1 종합 판정 | 다음 실험 |
|---|---|
| 도달하지 못함·부분 도달 | **B2 학습 규모 확대**(검토 문서 6.2-4): B1 설정에 개체군 64, 후보당 16교전. 설계와 기준은 B1 결과를 보고 실행 전에 이 문서에 덧붙인다 |
| 높은 수준에 도달 | **B3 하이브리드 재학습**(6.2-6): B1 모델 가운데 미리 정한 규칙(1,000세대 전원 대전 점수 1위)으로 고른 모델 위에 잔차형·게이팅형 300세대·5시드 |

`추가실험_사전기준.md`의 E4(본실험 설정 위의 규모 확대)는 실행 전에 취소하고 B2로 대체한다.
E1(학습 연장)은 낮은 우선순위로 계속 돌리고, E2·E3는 B1 뒤로 미룬다.

## 4. 분석 (검토 문서 6.3)

* B1 모델(300·600·1,000세대)을 위 절차로 평가하고 D\*(95%·90%), F(4), 종료 사유를 잰다.
* 두 트레이드오프 검정(연관성, 제약 비용)을 (가) 본실험 조건 + B1 모델, (나) B1 모델만으로 따로 계산한다.
  성능 범위가 넓어졌을 때 결론이 바뀌는지가 핵심이다.

## 5. 결과별 원고 처리 (검토 문서 6.4)

| 결과 | 원고 처리 |
|---|---|
