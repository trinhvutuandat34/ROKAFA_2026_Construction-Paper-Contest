# dfxai — 공중전 AI 의 전투성능·설명가능성·규칙준수 관계 실험

**dfxai** = **d**og**f**ight(도그파이트, 근접 공중전) + **XAI**(eXplainable AI,
설명가능 인공지능). "도그파이트 AI 의 설명가능성 실험"을 줄인 패키지 이름이며,
코드 폴더 `dfxai/` 와 실행 명령(`python -m dfxai.…`)에 그대로 쓰입니다.

논문 「공중전 인공지능 모델의 설명가능성과 전투성능 상관관계 분석」의 실험
프레임워크이자 **팀 공용 실험 기록**입니다. 코드를 읽지 않아도 이 문서와
`paper/` 폴더의 문서만으로 논문을 쓸 수 있도록 방법·결과·해석·실패 이력을 전부
적었습니다. 숫자는 2026-09-15 본실험(학습 시드 20개, 282조건, 112,800교전)과
확장 분석(`paper/results_ext.md`) 기준이며, 원본 표는 `paper/results_auto.md` 에 있습니다.

## 0. 한눈에 보기

**연구 질문.** 1대1 기총 도그파이트에서 규칙 기반 AI(행동트리)·학습 기반 AI
(신경망)·둘의 혼합을 **같은 환경, 같은 관측, 같은 행동공간, 같은 잣대**로
비교하면, 전투성능과 설명가능성 사이에 어떤 관계가 있는가?

> **쉽게 말하면.** 조종사 셋을 비교하는 실험이다. 첫째는 교범의 체크리스트대로만
> 움직이는 조종사(규칙 기반, 행동트리), 둘째는 수천 번의 모의 교전을 치르며
> 스스로 요령을 익힌 조종사(학습 기반, 신경망), 셋째는 둘의 조종간 입력을 섞은
> 조종사(혼합)다. 세 명을 같은 비행기, 같은 계기판, 같은 조종간으로 같은 상대와
> 싸우게 한 뒤 (1) 얼마나 이기는지, (2) 그 조종을 "이럴 땐 이렇게" 식의 짧은
> 규칙 몇 단계로 설명할 수 있는지, (3) 최저고도·G 한계 같은 안전규칙을 얼마나
> 지키는지를 잰다. 통념은 "잘 싸우는 조종사일수록 왜 그렇게 했는지 설명하기
> 어렵다"인데, 그것이 정말인지 숫자로 재는 것이 이 연구다.

### 0.0 처음 읽는 분께 — 이 연구의 출발점

상식적으로 생각하면 이렇다. 행동트리(BT)는 "고도가 낮으면 상승, 적이 기수 앞에
있으면 사격"처럼 **사람이 쓴 규칙**이므로, 왜 그렇게 움직였는지 규칙을 읽으면
바로 안다. 신경망은 숫자 수천 개가 얽혀 지령을 내므로 왜 그랬는지 읽을 수 없다
(**블랙박스**). **이 말은 맞고, 이 연구도 그것을 부정하지 않는다.** 여기서
자연스럽게 세 줄짜리 가설이 나오며, 이것이 연구의 출발점이었다.

* **H1.** 규칙 기반(BT)은 설명은 되지만 성능이 떨어진다.
* **H2.** 학습 기반(신경망)은 성능은 높지만 설명이 안 된다.
* **H3.** 둘을 섞은 혼합은 설명이 되면서 성능은 그 중간쯤일 것이다.

이 세 줄을 실제로 재려면 벽에 부딪힌다. "BT 는 설명 가능, 신경망은 불가능"이라고
**모델 종류로 정해 버리면** 설명가능성은 재는 값이 아니라 이름표가 된다. 그러면
H1·H2 는 성능만 비교하면 끝이고(설명가능성 쪽은 물어볼 것이 없다), H3 의 혼합은
"얼마나 설명 가능한지"를 잴 방법 자체가 없다. 그래서 이 연구는 설명가능성을
**두 층**으로 나눈다.

| | 뜻 | 누가 갖는가 | 어떻게 재나 |
|---|---|---|---|
| **내재적 설명가능성** | 모델 **속**을 사람이 읽을 수 있는가 | BT 있음 · 신경망 없음 · 혼합은 절반 | 모델 종류로 이미 정해짐. 측정 대상이 아니라 **전제** |
| **행동 수준 설명가능성** | 모델이 **실제로 한 조종**을 몇 단계 if-then 규칙으로 옮겨 적을 수 있는가 | 셋 다 잴 수 있음 | 행동 로그에 결정트리를 맞춰 필요한 깊이 **D\***(4.2절)를 구함. 작을수록 설명이 쉬움 |

첫 번째 층은 상식대로이고 논문에서도 그렇게 쓴다. 이 연구가 **숫자로 잰 것은 두
번째 층**이다. 두 번째 잣대에서는 BT 라도 행동이 복잡하면 설명이 어렵고(BT-v2
D\*=4, BT-v3 D\*=5), 신경망이라도 행동이 단순하면 설명이 쉽다(300세대 정책 20개
중 16개가 D\*≈5). 비유하면, 첫 번째 층은 "이 조종사가 교범을 외웠는가"이고 두
번째 층은 "이 조종사가 오늘 한 기동을 교범 몇 줄로 적을 수 있는가"이다. 교범을
외운 조종사도 실제 기동은 복잡할 수 있고, 감으로 나는 조종사도 기동은 단순할 수
있다.

두 번째 잣대로 세 가설을 재본 결과는 다음과 같다(숫자는 6절·8절).

| 처음 가설 | 실제로 나온 것 | 판정 |
|---|---|---|
| H1. BT 는 설명되지만 약하다 | 설명은 쉽다(D\* 4–5). 성능은 학습 정책보다 약간 낮지만(0.671 대 0.716) 제한시간을 240 s 로 늘리거나 시간종료를 무승부로 바꾸면 BT-v2 가 오히려 앞선다 | 설명 쪽은 맞고, "약하다"는 규칙에 따라 다름 |
| H2. 신경망은 강하지만 설명이 안 된다 | 성능은 더 높다(20개 중 17개가 BT-v2 초과). 그러나 행동 수준에서는 20개 중 16개가 BT-v3 와 같은 D\*≈5 였고, 설명이 어려운 4개(D\* 8–17)는 성능이 아니라 **전술**('끝까지 추격')이 달랐다 | 성능 쪽은 맞고, "설명이 안 된다"는 자기 로그 D\* 기준으로 틀림(공통 상태 D\* 로 재면 학습 정책 중앙값 17 대 규칙 모델 3–5 로 맞음, 6.2절) |
| H3. 혼합은 설명되면서 성능은 중간 | 지령을 섞은 혼합은 D\* 14–16 으로 **셋 중 가장 설명이 어렵고** 성능은 순수 학습 정책과 비슷하거나 낮다. 규칙이 학습 정책을 감독하는 혼합(Shield)은 하드덱·과G 위반을 거의 없애지만(완전한 0 은 아님, 6.6절) 점수 0.543, D\* 12. 확장 실험의 잔차형(규칙 + 학습 보정)은 BT-v2 보다 강해지지 못한 채 D\* 가 4 → 6–17, 게이팅형(비율 학습)은 성능은 순수 학습에 근접했지만 D\* 3 과 4 인 두 정책을 섞은 결과가 17(절단) | 틀림. 혼합 네 방식 모두 절충점이 아니었다 |

정리하면 "잘 싸우는 모델일수록 설명이 어렵다"는 **트레이드오프는 이 환경에서
관측되지 않았고**, 설명이 어려운지를 가른 것은 모델 종류나 성능이 아니라 **어떤
전술을 쓰는가**였다. "가설이 맞았다"가 아니라 "가설을 같은 잣대로 재봤더니 이렇게
됐다"가 이 논문이며, 심사 관점에서는 후자가 더 강한 기여다(통념을 측정으로 뒤집은
것이므로).

**읽는 순서.** 0.1 용어 → 1 배경·가설 → 3 비교 모델(3.1 BT 3종의 규칙 전문, 3.5
대전 방식과 결과 한눈에) → 4 세 평가축(특히 4.2) → 6 결과 → 8 결론. 논문을 쓸 때는 `paper/논문_골격.md` 가 절별 설계도다.

**핵심 결과 (20시드 본실험).** 숫자 읽는 법: 점수는 0(전패)–1(전승)이고 0.5 가
대등, D\* 는 작을수록 설명이 쉽고(1–16, 17 은 "16단계로도 안 됨"), 위반율은 0 이
완전 준수다. 용어는 0.1절 표에 정리했다.

1. 학습 정책은 규칙 기반 최강 모델(BT-v2)을 이긴다: 300세대 점수 **0.716 ± 0.051**
   (시드 20개, 범위 0.597–0.785) 대 0.671. 20개 중 17개가 BT-v2 평균을 넘고 18개는
   BT-v2 상대 순수승률이 Holm 보정 후 유의하게 0.5 를 넘는다. 학습에 쓰지 않은
   상대(BT-v3)에도 평균 0.746. 단, 이 우위는 **교전 규칙에 의존한다**: 제한시간을
   240 s 로 늘리거나 시간종료를 무승부로 바꾸면 BT-v2 가 학습 정책 평균을 앞선다
   (6.9절 R7).
2. 학습 예산이 늘수록 성능은 단조 상승(Spearman ρ=0.45, p=0.0003)하고 규칙
   위반은 절반으로 감소(0.096 → 0.050)했다.
3. **성능과 설명가능성 사이에 트레이드오프는 없다.** 282개 조건에서 점수–D\*
   순위상관 ρ=−0.02 (p=0.75), 학습·혼합 정책만 보면 ρ=−0.18 (p=0.006, 약한 음).
   부트스트랩 동등성 검정(TOST)으로 |ρ| < 0.2 가 지지되고, 잡음 감쇠를 보정해도
   ρ=−0.02, 학습 시드 임의효과 모형에서 D\* 계수 p=0.82 다. 충실도 임계값을
   0.90–0.97 로 바꿔도, 문턱 없는 F(4)·평균 F 로 바꿔도 같다(`paper/results_dstar_validity.md` R9b).
   **단, 정책이 가지 않는 상황까지 묻는 공통 상태 D\* 는 다르다.** 점수와 +0.19
   (p=0.001)이고 상태 방문 범위를 통제해도 +0.16 (p=0.007)으로 남으며, 90% CI
   [0.10, 0.27] 이 ±0.2 를 벗어나 동등성 검정도 성립하지 않는다(R9a). 이때 학습 정책의
   D\* 중앙값은 17 로 규칙 모델(3–5)보다 크다. 따라서 "잘 싸우는 모델은 설명하기
   어렵다"는 통념은 **정책이 실제로 겪은 상황에서 잰 설명 비용**에서는 관측되지 않았고,
   공통 상태에서는 작은 양의 상관이 남는다.
4. 설명가능성을 좌우한 것은 성능이 아니라 **규칙 복제본을 떠났는가**와 **전술
   유형**이었다. (a) D\* 는 복제본 2 에서 첫 체크포인트(25세대)에 7 로 뛴 뒤 300세대
   까지 평평하다(25세대 간격 12시드: 초기 7.8 대 후기 8.4, p=0.73). 8시드 시점에
   보였던 '산 모양'은 세밀 해상도에서 재현되지 않았다. (b) 같은 예산의 정책 20개가
   D\*=3–17 로 갈렸고, 전술 군집(가우시안 혼합, BIC)이 D\* 를 유의하게 가른다
   (Kruskal–Wallis p<0.0001): '한 번 쏘고 이탈'(16개, D\* 중앙값 5) 대 '끝까지
   추격'(4개, 12.5–14). 군집 안에서는 점수–D\* 상관이 전부 없다. (c) 지령을 섞은
   선형 혼합은 어느 쪽보다 설명하기 어렵고(D\* 14–16), 규칙이 학습 정책을 감독하는
   혼합(Shield)도 위반은 0 에 가깝지만 D\* 12 로 규칙 모델보다 복잡하다.
5. 규칙 준수는 '규칙으로 막기'와 '벌점으로 줄이기'의 문제다. 안전규칙을 트리에 명시한
   BT-v3 는 하드덱·과G 위반이 400교전 모두 0 이고, 감독형 혼합은 8,000교전 중 하드덱
   30교전·과G 3교전에서만 위반해 거의 0 이지만(증명된 보장은 아님), 둘 다 점수를 내준다(0.329, 0.543). 학습
   정책은 벌점만으로 위반을 BT-v2 의 절반(0.050)까지 낮추면서 성능도 올렸지만
   0 은 아니다. 상수를 같은 예산으로 최적화한 BT(BTO)는 D\* 3 으로 가장 단순하고
   보류 상대에 가장 강하지만(0.88) BT-v2 에는 진다(0.32).

된다.

| 용어 | 뜻 | 예시 |
|---|---|---|
| 교전 | 두 기체가 120초 동안 싸우는 모의전 1판 | 청군 BT-v2 대 홍군 학습 정책, 시드 17번 초기조건 |
| 시드 | 무작위 초기조건(거리·고도·방위)을 정하는 번호. 같은 시드면 같은 초기조건 | "100시드"는 서로 다른 초기조건 100가지 |
| 점수 | 승 1 · 무 0.5 · 패 0 의 평균. 0.5 가 대등 | 60승 20무 20패면 (60 + 10) / 100 = 0.70 |
| 순수승률 | 무승부를 빼고 센 승률 | 위 예에서 60 / (60 + 20) = 0.75 |
| 격추승 / 시간종료승 | 상대 HP 를 0 으로 만들어 이김 / 120초가 지나 남은 HP 가 더 많아 이김 | HP 100 대 91 로 끝나면 시간종료승 |

| 하드덱 | 훈련 안전상 내려가면 안 되는 최저고도(1,000 m) | 900 m 로 내려가면 위반 |
| 위반율 | 적분 스텝(0.05초) 가운데 안전규칙(하드덱·8 G·최소이격 150 m)을 어긴 비율 | 2,400스텝 중 120스텝 위반이면 0.05 |
| 규칙 기반 / 학습 기반 / 혼합 | 이 연구가 비교하는 세 계열. 사람이 규칙을 써 준 것 / 스스로 익힌 것 / 둘의 지령을 섞은 것 | BT / 신경망 / α 혼합 |
| 행동트리(BT) | "조건이면 행동" 노드를 위에서부터 훑는 규칙 정책. 사람이 그대로 읽을 수 있다 | "고도 1,400 m 아래? → 날개 수평, 상승" |
| 학습 정책 | 신경망(MLP). 숫자 1,827개가 관측을 지령으로 바꾸며 사람이 읽을 수 없다. 흔히 "RL 모델"이라 부르는 자리 | 관측 20개 → 뱅크·G·스로틀 3개 |
| 블랙박스 | 입력과 출력은 보이지만 그 사이 결정 과정을 사람이 읽을 수 없는 모델 | 신경망 |
| 강화학습(RL) / 진화전략(ES) | 둘 다 "교전을 반복하며 보상이 커지도록 정책을 고치는" 학습법. RL 은 교전 안의 매 순간 보상을 되짚어 가중치를 고치고, ES 는 정책을 여러 개 조금씩 흔들어 잘 싸운 쪽으로 옮긴다. 이 연구의 주 학습법은 ES 이고 PPO(RL)는 통제 조건 | 300세대 ES, 150만 스텝 PPO |
| 내재적 설명가능성 | 모델 **속**을 사람이 읽을 수 있는가. 모델 종류로 정해진다 | BT 있음, 신경망 없음 |
| 행동 수준 설명가능성 | 모델이 **실제로 한 조종**을 몇 단계 규칙으로 옮겨 적을 수 있는가. 모델 종류와 무관하게 잰다. 이 연구의 측정 대상 | D\* |
| 트레이드오프 | 한쪽을 얻으면 다른 쪽을 내주는 관계. 여기서는 "성능이 오르면 설명가능성이 내려간다" | 관측되지 않음(ρ=−0.02) |
| 세대(학습 예산) | 진화전략이 정책을 한 번 개선하는 단위. 세대가 많을수록 오래 학습한 것 | 100세대 ≈ 10분, 300세대 ≈ 30분 |
| 학습 시드 | 학습 과정의 무작위성을 정하는 번호. 같은 설정도 시드가 다르면 다른 정책이 나온다 | 시드 0 은 '치고 빠지기', 시드 1 은 '끝까지 추격' (20개 중 16 대 4) |
| α(혼합계수) | BT 지령과 학습 지령을 섞는 비율. 0 이면 BT 만, 1 이면 학습 정책만 | α=0.25 는 BT 75% + 학습 25% |
| 대리모델 | 정책의 행동 로그를 흉내 내도록 따로 만든 결정트리. 정책을 사람이 읽을 수 있는 규칙으로 "번역"한 것. 원 정책이 BT 든 신경망이든 같은 방법으로 만든다 | 학습 정책의 조종을 규칙 6단계 트리로 근사 |
| 충실도 F(d) | 깊이 d 인 대리 트리가 원 정책의 지령을 얼마나 맞히는가(R², 1 이면 완벽) | F(4)=0.93 이면 4단계 규칙으로 93% 재현 |
| D\* | 충실도 0.95 를 처음 넘기는 트리 깊이. **작을수록 설명이 쉽다** | D\*=3 이면 3단계 if-then 으로 R² 0.95 만큼 설명 |
| 절단(17) | 깊이 16까지 해도 0.95 에 못 미침. "17 이상"이라는 뜻 | 시드 1 의 300세대 정책 |
| 진영 교대 | 같은 시드로 청군·홍군을 바꿔 한 번 더 싸움. 초기조건 유불리를 상쇄 | 100시드 × 2 = 200교전 |
| 보류 상대 | 학습 때 한 번도 만나지 않은 상대. 이 상대에게도 이기면 과적합이 아니다 | BT-v3 |
| ρ (스피어만 순위상관) | 두 지표의 순위가 같이 움직이는 정도. +1 같은 순서, −1 반대, 0 무관 | 점수–D\* ρ=−0.02 는 "무관" |
| p 값 | 실제로는 관계가 없는데 우연히 이 정도 값이 나올 확률. 0.05 미만이면 "유의" | p=0.75 는 우연으로도 흔히 나오는 값 |

## 1. 연구 배경과 질문

### 1.1 배경과 상식적인 그림

공중전 AI 는 AlphaDogfight Trials(2020) 이후 강화학습 정책이 숙련 조종사를 이기는
수준에 이르렀다. 그러나 군 운용에서는 이기는 것만으로 부족하다. 교리 검증, 사고
조사, 조종사 신뢰, 교전규칙 준수 확인을 위해 "왜 그렇게 기동했는가"를 사람이
확인할 수 있어야 한다. 여기서 상식적인 그림이 하나 있다.

* 행동트리 같은 **규칙 기반** 모델은 사람이 쓴 규칙이므로 설명이 되지만, 사람이
  미리 써 둔 것만 하므로 성능이 낮다.
* 신경망 같은 **학습 기반** 모델은 스스로 익혀 성능이 높지만, 내부를 읽을 수
  없어 설명이 안 된다.
* 그러니 둘을 **섞으면** 설명은 되면서 성능은 그 사이 어딘가일 것이다.

이 그림이 0.0절의 H1·H2·H3 이고, 이 연구는 그것을 **같은 환경·같은 관측·같은
행동공간·같은 잣대**로 측정한다. 세 계열을 한 과업에서 같은 잣대로 잰 연구는
드물다(대부분 한 계열 안에서의 개선이거나, 계열마다 다른 지표를 쓴다).

### 1.2 왜 그대로 잴 수 없는가 — 설명가능성의 두 층

위 그림의 "설명이 된다/안 된다"는 **내재적(intrinsic) 설명가능성**, 즉 "모델
내부를 사람이 읽을 수 있는가"를 말한다. 이 뜻에서 BT 는 정의상 설명 가능하고
신경망은 정의상 블랙박스다. 이것은 맞는 말이고 논문에서도 그렇게 쓴다. 문제는
이 뜻으로는 **H1–H3 을 검증할 수 없다**는 점이다.

* 설명가능성이 모델 종류로 이미 정해지므로 잴 것이 없고, 남는 비교는 성능뿐이다.
  그러면 "BT(0.671) < 학습 정책(0.716)"이라는 성능 결과가 자동으로 "트레이드오프
  확인"으로 읽힌다. 이는 측정이 아니라 동어반복이다.
* 혼합 정책은 BT 절반 + 신경망 절반이라 "얼마나 설명 가능한지"를 이 뜻으로는 잴
  방법이 없다. H3 은 검증 불가능한 문장이 된다.
* 같은 BT 라도 노드가 많고 조건이 얽히면 사람이 읽기 어렵고, 같은 신경망이라도
  "적을 보면 곧장 쫓는다"처럼 단순한 행동만 하면 사람이 쉽게 예측한다. 내재적
  정의는 이 차이를 보지 못한다.

그래서 이 연구는 두 번째 층, **행동 수준(behavioral) 설명가능성**을 도입한다.
정책이 무엇으로 만들어졌든, 그 정책이 **실제로 낸 조종 행동**을 "몇 단계짜리
if-then 규칙으로 재현할 수 있는가"를 잰다. 구체적으로는 정책의 (관측, 지령)
로그에 결정트리를 맞추고, 원 지령을 R² 0.95 이상으로 재현하는 데 필요한 최소 깊이 D\* 를
구한다(4.2절). 이 잣대는 BT·신경망·혼합에 똑같이 적용되므로 세 계열을 한 축 위에
놓을 수 있고, BT 3종도 표본 안에 들어간다. 문헌으로는 사후 설명 기법 가운데
모델 무관(model-agnostic) 대리모델 계열(Ribeiro et al. 2016 LIME, Bastani et al.
2018 VIPER)에 속하며, "설명 가능한 모델은 반드시 약한가"라는 Rudin(2019)의 문제
제기를 한 과업에서 실측한 것으로 위치시킨다.

두 층의 관계를 한 줄로 적으면 이렇다. **내재적 설명가능성은 모델을 고르는 순간
정해지는 전제이고, 행동 수준 설명가능성은 그 모델이 실제로 얼마나 단순하게
행동하는지의 측정값이다.** 결론의 "상관 없음"은 뒤쪽 잣대에 대한 진술이다. 앞쪽
잣대로 "BT 는 설명 가능하다"는 문장은 여전히 참이며, 논문은 이 둘을 섞지 않도록
서론에서 한 문단으로 구분한다.

### 1.3 연구 질문

세 가설을 검증 가능한 질문으로 바꾸면 다음 세 가지다.

* **RQ1.** 규칙 기반·학습 기반·혼합 모델의 전투성능과 (행동 수준) 설명가능성
  사이에 어떤 관계가 있는가? — H1·H2·H3 을 한 평면 위에서 함께 본다.
* **RQ2.** 학습 예산(학습량)이 늘 때 두 축은 어떻게 함께 움직이는가? — "학습할수록
  블랙박스가 된다"는 H2 의 동적인 판.
* **RQ3.** 규칙 준수(안전 제약)는 이 관계에서 어떤 위치에 있는가? — 운용에서
  설명가능성을 요구하는 실제 이유(안전·교리 준수)와 연결.

### 1.4 기여

(i) 모델 계열에 무관하게 행동 로그만으로 계산되는 설명가능성 지표(대리모델 최소
깊이 D\*)로 규칙·학습·혼합을 처음으로 한 축에 놓은 것, (ii) 초기조건 편향을
제거한 진영 교대 짝지은 평가 설계, (iii) 학습 예산 × 혼합계수 2차원 스윕과 학습
시드 20개로 "점 몇 개"가 아닌 관계의 **형태**를 보인 것. 결과는 절대 순위가
아니라 형태에 대한 주장이다.

## 2. 실험 환경

### 2.1 왜 대회 환경이 아니라 별도 시뮬레이터인가

항공대 대회 프레임워크는 조종간·페달·스로틀을 직접 제어하는 고차원 입력이라
강화학습이 붙기 어렵고, 교전 1회에 수 초가 걸려 수만 회 학습이 불가능하다.
그래서 논문 실험용으로 **통제 가능한 축소 환경**을 만들었다. 대회 환경은 외부
검증·시연용으로 남긴다. 축소 환경의 설계 원칙 세 가지:

* **행동공간 추상화.** 정책은 `뱅크각 지령 · 하중배수(G) 지령 · 스로틀 지령`
  3채널만 낸다. 3자유도 점질량 모델의 자연스러운 입력이라 물리적으로 타당하고,
  세 모델 계열이 **같은 지령 공간**을 쓰게 되어 설명가능성 비교가 공정해진다.
* **관측 압축.** 원시 상태(위치·속도 12차원) 대신 교전기하 20차원(거리, 기수-시선
  각 ATA, 애스펙트각 AA, 접근률, 고도차, 비에너지차, 잔여 HP, 경과시간 등)을
  쓴다. 도그파이트는 이 좌표계에서 사실상 완전히 기술된다.
* **혼합 다이얼.** `a = (1−α)·a_BT + α·a_RL` 한 줄로 세 계열을 잇는다. α 를
  관측에 포함시켜 학습하면 **정책 하나가 모든 α 에서 동작**한다.

> **예시.** 정책이 매 0.2초마다 받는 관측 20개를 말로 풀면 이렇다: "상대는 2.1 km
> 앞, 내 기수에서 왼쪽 30°(ATA), 상대는 내게 꼬리를 보이는 중(AA 150°), 초당
> 90 m 씩 가까워짐, 상대가 400 m 위, 내 에너지가 약간 우세, 내 HP 100 상대 HP 75,
> 경과 38초, α=1.0". 정책이 내는 지령 3개는 "왼쪽으로 60° 뱅크, 6 G 당김, 스로틀
> 100%" 같은 식이다. 원시 좌표(x, y, z, 속도)를 주지 않는 이유는 "상대가 어디에
> 있고 어느 쪽을 보는가"만 알면 도그파이트 판단에 충분하고, 그 좌표계에서는 규칙
> 정책과 학습 정책의 행동을 같은 말로 비교할 수 있기 때문이다.

### 2.2 시뮬레이터

* 기체: F-16급 공개 제원의 3자유도 점질량 모델(질량 9,300 kg, 익면적 27.87 m²,
  CL_max 1.6, 해면 최대추력 106 kN, 구조한계 9 G). 양력 한계와 구조 한계 중 작은
  값이 가용 G 가 되어 **코너속도가 자연스럽게 창발**한다. 뱅크·G·스로틀은 1차
  지연(0.35/0.30/1.2 s)으로 지령을 따른다.
* 적분: 명시적 오일러 0.05 s, 제어주기 0.2 s(5 Hz), 교전 120 s.
* 기총 WEZ: 거리 120–1,200 m 이고 보어사이트 이탈각(ATA)이 명중 원추 안이면
  25 HP/s 피해. 원추 반각은 대회 규정처럼 3° 에서 10° 로 시간에 따라 넓어진다.
* 종료: 상대 HP 0 → 격추승, 고도 0 → 지면충돌패, 거리 60 m 미만 → 공중충돌
  (양측 패 = 무승부), 120 s → 잔여 HP 비교(같으면 무승부).
* 초기조건: 거리 1.5–3.5 km, 고도 3–5 km, 속도 180–260 m/s 를 양측 동일하게 두고
  각자의 기수방위만 무작위. 잔여 편향은 진영 교대(§5.1)로 상쇄.
* 속도: 교전 1회 약 0.02 s(단일 코어). 의존성은 numpy·pandas·scipy·scikit-learn·
  matplotlib, 행동 복제 초기화에만 torch.

> **예시.** 거리 600 m 에서 상대가 내 기수 앞 4° 안에 들어오면 명중 원추 안이므로
> 초당 25 HP 가 깎인다. 3초 유지하면 75 HP, 4초면 격추다. 같은 자세라도 거리가
> 1,500 m 면 사거리 밖이라 피해가 없다. 한 번 3초 스치고 이후 다시 붙지 않으면
> 120초 뒤 HP 100 대 25 로 시간종료승이 된다 — 6.4절의 '치고 빠지기'가 바로
> 이 방식이다.

전체 수치는 `paper/results_auto.md` 부록 A(config.py 스냅샷)에 있다. 값을
바꾸면 부록도 자동으로 바뀐다.

## 3. 비교 모델

세 계열 모두 **관측 20차원 → 지령 3차원**의 같은 인터페이스를 쓴다.

### 3.1 규칙 기반: 행동트리(BT) 3종

**BT 는 학습시키지 않았다.** 세 트리 모두 사람이 기본전투기동(BFM) 교범의 표준
전술을 if-then 규칙으로 옮겨 쓴 것이다(`dfxai/agents/bt.py`, 약 250줄). 규칙 기반
계열이 "사람이 쓴 규칙"이어야 0.0절의 내재적 설명가능성이 성립하므로, 상수 하나도
데이터로 맞추지 않았다. 상수를 학습으로 맞춘 규칙 모델은 따로 BTO 라는 이름으로
두었고 이 절 끝과 3.4절에서 설명한다.

**행동트리가 무엇인가.** 노드 네 종류로 만든 나무다. **Selector** 는 자식을 위에서
부터 시도해 처음 성공하는 자식에서 멈춘다(우선순위 분기). **Sequence** 는 자식이
모두 성공해야 성공한다("조건이면 행동"). **Condition** 은 관측을 보고 참/거짓을
내고, **Action** 은 지령(뱅크·G·스로틀)을 쓴다. 매 제어주기 0.2초마다 루트에서
한 번 훑고(tick), 마지막으로 실행된 Action 이 그 순간의 조종이 된다. 노드 수는 곧
"이 조종사가 따르는 질문과 행동의 개수"이며, 표 M1 의 복잡도 열이 이것이다.

**세 트리가 공유하는 최우선 노드: 정면 합류 회피(`merge_avoidance`).**
조건은 네 가지가 동시에 참일 때다. 거리 1,000 m 이내, 접근률 200 m/s 초과, 상대의
애스펙트각(AA) 140° 초과(상대도 나를 향하고 있음), 내 기수 이탈각(ATA) 40° 미만
(나도 상대를 향하고 있음). 행동은 상대가 있는 쪽의 **반대**로 75° 뱅크, 5 G, 스로틀
최대. 양측이 같은 규칙을 쓰면 각자 자기 기준 반대편으로 꺾으므로 서로 멀어진다.
정확히 정면이면 우측 회피(항공 규칙의 관례). 이 노드는 처음부터 있던 것이 아니라
개발 중 추가됐다 — 아래 "개발 과정".

**BT-v1 수평 추격 (노드 8, 교리: 초급 수평 선회전).** 수직면을 전혀 쓰지 않는다.

1. 정면 합류 회피 (공통).
2. 기수가 이미 정렬됐는가(수평 이탈각 3° 이내)? → 날개 수평, 4 G, 스로틀 80%.
3. 그 밖에는 → 상대가 있는 쪽으로 75° 뱅크, 4 G 고정, 스로틀 80%.

**BT-v2 3차원 최대선회 (노드 5, 교리: 순수추격 최대 선회율).** 가장 짧은 트리이며
가장 강하다.

1. 정면 합류 회피 (공통).
2. 그 밖에는 → **양력벡터를 시선에 맞춘다.** 필요한 뱅크각 = atan2(수평 이탈각,
   수직 이탈각). 상대가 아래에 있으면 뱅크가 90° 를 넘어 기수 하향 선회가 된다.
   G 는 그 순간 낼 수 있는 최대(양력 한계와 구조 한계 9 G 중 작은 값), 스로틀
   100%. 하드덱과 과G 를 전혀 고려하지 않는다.

**BT-v3 3차원 + 안전규칙 (노드 11, 교리: v2 + 훈련 안전규칙 + 사격 시 리드추격).**

1. 정면 합류 회피 (공통).
2. 하드덱 회복: 고도가 하드덱(1,000 m) + 400 m 아래이고 아직 상승 중이 아닌가
   (비행경로각 0.05 rad 미만)? → 날개 수평, 약 3 G 로 완만히 상승, 스로틀 최대.
3. 사격 추적: 거리 1,100 m 이내이고 총 이탈각 0.20 rad(약 11°) 이내인가? → 리드
   추격(리드 게인 1.25, 상대의 앞을 겨눔), G 상한 8.
4. 그 밖에는 → v2 와 같은 양력벡터 지향 순수추격, 단 G 상한 8, 스로틀 100%.

> **BT-v3 를 조종사 말로 읽으면.** "정면으로 빠르게 다가오면 옆으로 비켜라. 낮으면
> 먼저 고도를 회복하라. 사거리 안에 기수가 들어오면 상대 앞을 겨누고 8 G 안에서
> 당겨라. 아니면 상대 쪽으로 양력벡터를 돌려 8 G 안에서 최대 선회하라." 네 문장이
> 곧 트리이며, 사람이 그대로 읽을 수 있다는 것이 규칙 기반 모델의 특징이다.

**세 버전은 성숙도 사다리가 아니라 서로 다른 교리다.** 성능 서열은 v2 > v3 > v1,
규칙 준수 서열은 v3 > v1 > v2 로 **정반대**다. 즉 BT 3종만으로도 성능과 규칙 준수
사이의 긴장이 보인다. 행동 수준 설명가능성(D\*)은 v1 = 1, v2 = 4, v3 = 5 다. v1 이
1 인 이유는 거의 항상 같은 지령(75° 뱅크·4 G)을 내기 때문이고, 그래서 설명은 가장
쉽지만 거의 이기지 못한다(격추 19%). v2 가 노드 5개인데 D\* 가 4 인 이유는
atan2 로 계산하는 연속 함수를 if-then 계단으로 근사해야 하기 때문이다.

| 모델 | 노드 | 점수(상대 2종 평균) | vs BT-v2 | vs BT-v3 | D\*(0.95) | 위반율/스텝 | 종료 사유 |
|---|---|---|---|---|---|---|---|
| BT-v1 수평 추격 | 8 | 0.241 | 0.25 | 0.23 | 1 | 0.005 | 시간종료 74%, 격추 19% |
| BT-v2 3차원 최대선회 | 5 | **0.671** | 0.50 (자기 대전) | 0.84 | 4 | 0.100 (하드덱 0.049, 과G 0.044) | 시간종료 52%, 격추 32%, 지면충돌 8% |
| BT-v3 3차원 + 안전규칙 | 11 | 0.329 | 0.16 | 0.50 (자기 대전) | 5 | **0.008** (하드덱·과G 0) | 시간종료 60%, 격추 31% |

**개발 과정 — 학습 대신 사람이 한 일.** 첫 판본은 순수추격만 있었다. BT 둘을
붙이자 정면에서 서로를 향해 직진하다 60 m 안으로 들어와 **교전의 45–53% 가
공중충돌**로 끝났다. 이 상태로 학습 정책을 훈련하면 배우는 것은 전술이 아니라
"들이받는 상대 피하기"가 된다. 실제 BFM 에서 합류 시 측방 이격 유지는 기본
규칙이므로 세 트리 모두에 합류 회피 노드를 최우선으로 넣었고, 충돌은 3–10% 로
떨어졌으며 BT-v2 대 BT-v3 교전의 58% 가 격추로 끝난다(9.1절). 그 뒤로 BT 는
바꾸지 않았다. 사람이 들인 시간은 `paper/개발노력_기록.md` 에 있다.

**BTO — 상수를 학습시킨 BT (3.4절의 통제 조건).** "규칙 모델이 약한 것은 사람이
손으로 상수를 정해서다"라는 반론을 막기 위해, BT-v3 와 **구조·노드 수(11)를 그대로
두고 상수 9개만** 학습 정책과 같은 방식으로 학습시켰다(`dfxai/agents/bt_param.py`,
`dfxai/rl/train_es_bt.py`). 학습 대상 상수: 추격 시 G 사용 비율, 리드 게인, 사격
추적 진입 거리·총각, 하드덱 회복 여유, 합류 회피 개시 거리·접근률·뱅크, 스로틀.
학습 절차는 학습 정책과 같다 — BT-v3 상수 근방에서 출발, 진화전략(개체군 32, 후보당
8교전, 상대 BT-v1/v2 교대, 같은 적합도, 갱신 수용 검사) 300세대, 학습 시드 3개.
다른 것은 탐색 보폭뿐이다(9차원이라 σ 0.10·학습률 0.05, 신경망은 1,827차원이라
σ 0.05·0.01). 결과: 점수 0.60(3시드 0.594–0.610), 보류 상대 BT-v3 에는 가장 강하고
(0.87–0.89) BT-v2 에는 진다(0.32–0.33). D\* 3–5 로 가장 단순하고 하드덱 위반은 0,
격추로 끝나는 비율이 44–47% 로 올랐다. 상수를 최적화해도 손으로 만든 BT-v2 를 넘지
못했으므로, 이 환경에서 규칙 모델의 성능 한계는 상수 튜닝의 문제가 아니라 **구조**
(정해진 네 가지 상황 판단)의 문제다.

### 3.2 학습 기반: 신경망 정책 (MLP, 진화전략)

> **쉽게 말하면.** 신경망은 숫자 1,827개(가중치)로 관측을 지령으로 바꾸는
> 계산기다. 처음에는 BT-v2 가 싸운 로그 16만 줄을 보여주고 "같은 상황에서 같은
> 지령을 내도록" 숫자를 맞춘다(행동 복제 — 선배 조종사의 조작을 따라 하기).
> 그다음 진화전략으로 다듬는다: 한 세대마다 가중치를 32가지로 조금씩 다르게
> 흔들어 각각 8판씩 싸우게 하고, 잘 싸운 방향으로 가중치를 조금 옮긴다. 이것을
> 300번 반복한 것이 "300세대"다. 잘 싸웠는지를 매기는 점수표가 아래 **적합도**이며,
> 이 점수표에 허점이 있으면 정책은 싸우는 대신 허점을 파고든다(§9.2).

* 구조: 20-32-32-3 tanh MLP, 파라미터 1,827개. 순전파는 numpy.
* **초기화: BT-v2 행동 복제.** BT-v2 가 BT-v1/v2/v3 와 싸운 로그 161,694 샘플에
  MLP 를 회귀시켜(뱅크 채널 R² 0.95) 얻은 가중치에서 출발한다. 복제본은 본실험
  평가에서 BT-v2 상대 0.44, BT-v3 상대 0.84(평균 0.639)로 원본(0.50, 0.84)과 비슷하게 싸운다. 무작위 초기화가
  실패한 경위는 §9.2.
* **학습: OpenAI-ES 변형.** 미러 샘플링, 순위 정규화, σ 0.05, lr 0.01, 개체군 32,
  후보당 8교전(α 격자 {0.25, 0.5, 0.75, 1.0} × 2시드, 상대 BT-v1/v2 교대), 300세대.
  여기에 **갱신 수용 검사**를 더했다: 갱신 전후의 정책을 같은 시드로 평가해
  나빠지면 갱신을 거부하고 보폭을 줄인다(§9.3). 시드당 28–35분, 수용률 약 58%.
* **적합도(에피소드 스칼라)**: 0.2 × (가한 피해 − 받은 피해) + 0.5 × WEZ 체류초
  + 종료보상(격추승 +10, 시간종료승 +5, 격추패 −10, 시간종료패 −5, 공중충돌 −5,
  지면충돌 −15) + 0.5 × 평균 포텐셜 − 3 × (하드덱+과G 위반율) − 8 × [양측 무피해
  시간종료]. 포텐셜 Φ 는 ATA·AA·에너지 항에 근접 가중(사거리 밖 지수 감쇠)을 곱한
  것으로, 포텐셜 기반 셰이핑(Ng, Harada & Russell 1999)의 형태라 최적정책을 바꾸지
  않는다. 이 설계에 이르기까지의 실패는 §9.2.
* **학습 예산 축**: 체크포인트 0(복제본), 100, 200, 300세대. 학습 시드 20개
  (시드 8–19 는 25세대 간격으로도 저장해 세밀 예산 분석에 씀).
* α=1.0 정책은 MLP 만 실행하는 블랙박스다. "초기화를 BT 에서 했다"는 사실은
  방법 절에 명시하되, 학습 기반 모델이라는 정의는 유지된다.

### 3.3 혼합: BT + 학습 정책

`a = (1−α)·a_BT-v2 + α·a_RL`. 뱅크 채널은 각도(±1 = ±180°)라 **원형 평균**
(sin/cos 가중합의 atan2)을 쓴다. 선형 평균은 −170° 와 +170° 를 섞어 0° 를 내어
양력벡터를 정반대로 돌린다. α ∈ {0.25, 0.5, 0.75}. α 는 관측 벡터의 마지막
원소로 정책에 들어가므로 학습 정책 하나가 모든 α 에서 동작한다.

> **예시.** 같은 순간 BT-v2 가 "오른쪽 60° 뱅크", 학습 정책이 "오른쪽 20° 뱅크"를
> 내면 α=0.25 혼합은 0.75 × 60 + 0.25 × 20 = 50° 다. 문제는 각도가 ±180° 에서
> 이어진다는 점이다. BT 가 −170°, 학습 정책이 +170° 를 내면 둘 다 "거의 뒤집힌
> 자세"로 같은 뜻인데 선형 평균은 0°(수평)를 낸다. 원형 평균은 180° 를 내어 두
> 정책의 의도를 보존한다.

### 3.4 확장 계열 — 반론을 막기 위한 세 가지 통제 조건

본실험의 세 계열만으로는 "규칙 모델이 약한 것은 손으로 만들어서", "혼합이 나쁜 것은
선형 혼합이라서", "학습 계열이 진화전략 하나뿐이라서"라는 반론이 남는다. 그래서
같은 환경·같은 평가에 세 계열을 더했다.

| 계열 | 무엇인가 | 왜 넣었나 |
|---|---|---|

### 3.6 확장 하이브리드 — 잔차형·게이팅형 (2026-09-29 완료, 결과는 6.10절)

3.3절의 선형 혼합과 3.4절의 감독형 혼합(Shield)은 둘 다 절충점이 아니었다(6.5절).
그러나 그 결론은 "혼합 설계 방식 두 가지"에 대한 결론이지 "혼합 일반"에 대한 결론이
아니다. 설계 방식 자체를 변수로 놓기 위해 두 종류를 더한다. 설계 배경과 일정은
`paper/하이브리드_확장_실험설계.md`, 코드는 `agents/residual.py`·`agents/gating.py`·
`rl/train_es_hybrid.py`.

| 혼합 방식 | 누가 비율을 정하나 | 수식 | 상태 |
|---|---|---|---|
| 선형 혼합 (3.3) | 사람이 α 를 고정 | a = (1−α)·a_BT + α·a_RL | 완료 |
| 감독형 Shield (3.4) | 사람이 쓴 안전 조건이 스위치 | 안전 조건이면 BT, 아니면 RL(+8 G 상한) | 완료 |
| **잔차형 RES** | 규칙이 뼈대, 학습은 보정만 | a = a_BT-v2 + β·δ(o), δ = tanh(MLP) | 완료 (3시드) |
| **게이팅형 GATE** | 게이트 신경망이 상황마다 비율을 결정 | a = (1−g(o))·a_BT-v2 + g(o)·a_RL, g = sigmoid(MLP) | 완료 (3시드) |

> **쉽게 말하면.** 선형 혼합은 두 조종사의 조종간 입력을 정해진 비율로 섞는 것이고,
> Shield 는 위험할 때만 교관이 조종간을 잡는 것이다. 잔차형은 **교범대로 나는 조종사
> 위에 학습이 손끝 보정만 얹는 것**(조종간을 뒤집을 수는 없고 조금 더 당기거나 덜
> 당기는 정도), 게이팅형은 **"지금은 교범 70%, 감 30%"를 상황마다 스스로 정하는 것**이다.

**잔차형(RES).** 학습 정책은 완전한 지령이 아니라 BT-v2 지령에 더할 보정치 δ 만 낸다.
보정 허용폭 β=0.35 는 정규화 단위이므로 뱅크 최대 ±63°, 하중배수 최대 ±1.6 G,
스로틀 최대 ±17.5% 까지만 고칠 수 있다. 즉 학습이 규칙을 **뒤집을 수 없고 다듬기만**
할 수 있다. 신경망 구조는 순수 학습 정책과 같은 20-32-32-3(1,827개)이고, 가중치를
0 근방(표준편차 0.01)에서 출발시켜 첫 세대에는 BT-v2 와 거의 같은 행동을 낸다(1세대
|δ| 평균 0.011). 뱅크 채널은 더한 뒤 ±180° 에서 원형으로 감는다. 학습은 순수 학습
정책과 같은 진화전략(개체군 32, 후보당 8교전, σ 0.05, lr 0.01, 수용 검사, 상대
BT-v1/v2 교대, 같은 적합도)으로 200세대, 학습 시드 3개.

**게이팅형(GATE).** 혼합 비율 g 를 사람이 정하지 않고 작은 게이트 신경망(20-8-1,
177개)이 매 제어주기 관측을 보고 정한다. 학습 정책 절반은 새로 학습하지 않고
**학습 시드 11 의 300세대 체크포인트를 고정**해서 쓴다. 시드 11 은 '치고 빠지기'
군집(20개 중 16개)의 대표이며 점수 0.776(20개 중 2위)·D\*=3 으로 성능과 설명가능성이
둘 다 좋은 정책이라, 게이트가 여기에 규칙을 섞어 무엇을 얻거나 잃는지가 가장 선명하게
드러난다. 게이트만 같은 진화전략으로 200세대, 학습 시드 3개. 초기 g ≈ 0.5(선형 혼합
α=0.5 와 같은 출발점).

**붕괴 진단.** 두 계열은 "학습이 안 되는" 위험보다 "학습은 되는데 의도와 다른" 위험이
크다. 잔차형은 δ 가 0 으로 죽으면 BT-v2 와 같아지고, 게이팅형은 g 가 0 또는 1 로
굳으면 순수 BT 또는 순수 학습 정책과 같아진다. 그래서 학습기가 매 세대 |δ| 평균과
g 의 평균·표준편차를 history 에 기록하며(`results/es_res/history_seed*.json`,
`results/es_gate/`), 25세대 체크포인트마다 확인한다.

**평가.** 본실험과 같다. 상대 BT-v2·BT-v3, 100시드 × 진영 교대, 예산 축은 100·200세대
체크포인트, 조건명 `RES-s<시드>-b<세대>`·`GATE-s<시드>-b<세대>`. 세 축(점수·D\*·위반율)
모두 기존 파이프라인이 그대로 계산한다. 결과는 6.10절에 채운다.

**이 실험이 논문에 주는 것.** 5.3절 조건 격자의 혼합 4종(선형·감독형·잔차형·게이팅형)을
성능–D\* 평면에 함께 찍은 **트레이드오프 지도**다. 가설 H3("혼합은 설명되면서 성능은
중간")이 선형·감독형에서 틀렸다는 지금의 결론이 "혼합 방식을 잘못 골라서"인지 "혼합
일반의 성질"인지를 가른다. 잔차형이나 게이팅형이 "성능은 높고
D\* 는 낮은" 영역에 오면 H3 은 설계 방식에 따라 살아나고, 둘 다 선형 혼합 근처에 머물면 결론 4 는
더 강해진다. 어느 쪽이든 결과다. **실제 결과는 후자였다(6.10절).**

## 4. 세 평가축

### 4.1 전투 성능

주 지표는 **점수** = 승 1 · 무 0.5 · 패 0. 무승부가 적지 않으므로(BT-v2 자기대전
49%) 무승부 제외 **순수승률**과 **종료 사유 분포**(격추/시간종료/지면충돌/
공중충돌)를 반드시 함께 보고한다. 한쪽만 쓰면 결론이 무승부 처리 방식에
의존한다는 지적을 받는다. 보조: WEZ 체류시간, 피해량, 생존시간.

> **예시.** 정책 A 는 100판에서 60승 20무 20패, 정책 B 는 40승 60무 0패다. 점수는
> 둘 다 0.70 으로 같지만 순수승률은 A 0.75, B 1.00 이고 종료 사유도 다르다(A 는
> 격추가 많고 B 는 시간종료가 많다). 점수만 보고하면 "무승부를 0.5 로 친 탓에
> B 가 저평가됐다"는 반론을 받으므로 셋을 함께 낸다.

### 4.2 설명가능성: 대리모델 최소 깊이 D\*

**먼저 무엇을 재는지.** 1.2절의 두 층 가운데 이 지표는 **행동 수준** 설명가능성을
잰다. "BT 인가 신경망인가"(내재적)는 입력에 들어가지 않는다. 정책이 남긴 조종
기록만 보고, "이 조종을 사람이 읽을 수 있는 if-then 규칙 몇 단계로 옮겨 적을 수
있는가"를 센다. 그래서 같은 BT 라도 행동이 복잡하면 D\* 가 크고, 신경망이라도
행동이 단순하면 D\* 가 작다. 사람이 "이 모델이 다음에 뭘 할지 규칙으로 예측할 수
있는가"에 가장 가까운 기능적 정의이며, 사람의 실제 이해도와의 관계는 미검증이다
(10절 한계).

정책이 남긴 (관측, 행동) 궤적에 깊이 d 의 결정트리 회귀모델을 적합하고, 테스트
셋에서 원 정책의 행동을 재현한 정도(R², 채널 분산가중 평균)를 충실도 F(d) 라
한다. **D\* = F(d) ≥ 0.95 를 처음 만족하는 최소 깊이.** 작을수록 단순한 규칙으로
설명 가능하다. 깊이 16까지 검사해 미달이면 17로 **우측 절단**한다(생존분석의
censoring 과 같이 취급하며 논문에 명시). 보조 지표로 D\*(0.90), D\*(0.99), 깊이
4 고정 충실도 F(4)를 함께 낸다.

> **예시 — D\* 를 구하는 과정.** 어떤 학습 정책이 남긴 (관측, 지령) 쌍 수만 개를
> 모은다. 깊이 1 트리는 질문 하나로 지령을 정한다: "거리 < 800 m 이면 7 G, 아니면
> 4 G". 이것이 원 정책의 지령을 62% 재현했다면 F(1)=0.62. 깊이 2("거리 < 800 이고
> ATA < 20° 면 8 G, …")는 0.85, 깊이 3 은 0.96. 0.95 를 처음 넘긴 깊이가 3 이므로
> D\*=3 — "이 정책의 조종은 3단계 if-then 규칙으로 R² 0.95 만큼 설명된다(지령 변동의 95%; 지령의 95%가 일치한다는 뜻은 아님)". 반대로 깊이
> 16까지 늘려도 0.93 에 머무는 정책은 D\*=17(절단)로 적고 "규칙 16단계로도 설명이
> 안 된다"고 읽는다. BT 든 신경망이든 로그만 있으면 같은 절차로 구한다.

왜 이 지표인가: SHAP·보상분해 같은 기법은 특정 모델 계열에만 적용되지만, 이
지표는 **행동 로그만 있으면 계산**되어 BT·MLP·혼합에 완전히 동일하게 적용된다.
"BT 는 원래 트리라 유리하다"는 반론에는 두 가지로 답한다. 대리모델은 정책의
내부 구조가 아니라 관측된 행동에만 적합하고, 세 계열이 같은 관측·지령 공간을
쓴다. 실제로 BT-v2 는 노드 5개짜리 트리지만 arctan2 기반 연속 함수라 D\*=4 인
반면, 그것을 복제한 MLP 는 D\*=2 다 — 트리 구조가 유리한 것이 아니다.

지표 설계에서 잡은 함정 둘. **행동 포화**: 뱅크 지령 한계를 ±100° 로 두면 출력이
상시 포화되어 사실상 이진값이 되고 대리모델이 깊이 1로 R²=0.98 을 달성해
버린다. ±180° 로 넓혔다. **상수 채널**: 스로틀을 항상 최대로 두는 정책은 해당
채널 분산이 0이라 R²=1 이 되어 단순 평균이 지표를 부풀린다. 분산가중 평균으로
고쳤다.

주의: D\* 는 시드 간 분산이 크다(같은 예산에서 표준편차 5–7). 논문에서는 D\*
하나로 주장하지 말고 F(4)·충실도 곡선과 나란히 두어 방향이 일치함을 보인다.

### 4.3 규칙 준수

적분 스텝당 위반율. 하드덱(최저고도 1,000 m) 침범, 과G(8 G 초과), 최소이격
(150 m) 침범. 주관적 해석이 개입하지 않는 객관 지표다.

> **예시.** 교전 1판은 120초 ÷ 0.05초 = 2,400 스텝이다. 그중 하드덱 아래에 있던
> 스텝이 96개, 8 G 를 넘긴 스텝이 24개면 위반율은 (96 + 24) / 2,400 = 0.05 다.
> BT-v2 의 0.100 은 "열 스텝 중 하나는 무언가를 어기고 있다"는 뜻이고, BT-v3 의
> 하드덱 0.000 은 트리에 회복 규칙이 있어 단 한 스텝도 내려가지 않았다는 뜻이다.

## 5. 실험 설계

### 5.1 진영 교대 짝지은 평가

처음에는 같은 정책끼리 붙였는데 승률이 0.59 가 나왔다. 특정 시드의 초기조건이
청군에 유리했던 것이다. 그래서 **같은 시드로 청/홍을 바꿔 한 번 더** 싸우게
했고, 이후 자기대전 점수는 정확히 0.500 이 됐다(BT-v2, 100시드 × 2). 이 검증
자체를 논문 방법 절에 한 문장으로 넣으면 설계가 편향 없음을 보이는 근거가 된다.

> **예시.** 시드 17번 초기조건에서는 청군이 홍군의 꼬리 쪽에서 시작한다고 하자.
> 이 판만 보면 청군 정책이 이긴 것이 실력인지 자리 덕인지 알 수 없다. 같은 시드로
> 청·홍을 바꿔 한 번 더 싸우면, 실력이 같을 때는 1승 1패로 상쇄되고 실력 차가
> 있을 때만 2승 또는 2패가 남는다. 그래서 같은 정책끼리 붙인 검증에서 0.500 이
> 정확히 나온다.

### 5.2 통계

같은 시드의 두 판은 독립이 아니므로 **시드 단위로 평균한 뒤** 그 값들을
표본으로 삼는다. 점수의 신뢰구간은 Wilson 95%, 조건 간 비교는 같은 시드를
공유하므로 **대응표본 Wilcoxon**, 다중비교는 **Holm-Bonferroni**, 동전던지기
(0.5) 대비 순수승률은 이항검정. 조건 간 순위상관은 Spearman ρ 와 Kendall τ
(D\* 에 절단값이 있어 순위 기반이 적절).

> **각 통계가 답하는 질문.**
> * **Wilson 95% 신뢰구간** — "이 점수를 다시 재면 어느 범위에 들어오나". 0.72
>   (0.63–0.80)이면 다시 재도 대체로 그 사이.
> * **대응표본 Wilcoxon** — "같은 시드 100개에서 정책 A 와 B 의 점수 차이가
>   한쪽으로 쏠렸나". 시드마다 (A − B)를 구해 부호와 크기를 본다. 같은 초기조건을
>   공유하므로 초기조건 운은 빠지고 정책 차이만 남는다.
> * **Holm 보정** — 비교를 여러 번 하면 하나쯤은 우연히 유의해 보인다. 검정
>   10개를 했으면 가장 작은 p 는 0.05 / 10 = 0.005 아래여야 "유의"로 인정한다.
> * **이항검정** — "무승부 뺀 80판 중 65승이 동전던지기(0.5)로 나올 확률은?"
>   그 확률이 0.05 미만이면 실력이다.
> * **Spearman ρ** — 조건 282개를 점수 순, D\* 순으로 각각 줄 세워 두 순위표를
>   비교한다. 점수 1위가 D\* 도 1위, 2위도 2위… 면 +1, 완전히 반대면 −1. ρ=−0.02,
>   p=0.75 는 "두 순위표가 무관하고, 이 정도 값은 무관해도 흔히 나온다"는 뜻.

D\* 는 예산에 단조가 아니다. 복제본 2 → 100세대 8.1 → 200세대 7.2 → 300세대 7.6;

세밀 평가(시드 8–19, R6)로 형태를 확인하면:

|---|---|---|---|---|---|---|---|
| 점수 | 0.537 | 0.590 | 0.652 | 0.662 | 0.666 | 0.694 | 0.705 |
| D\* (자기 로그) | 7.2 | 7.3 | 7.7 | 6.2 | 7.1 | 8.6 | 8.2 |

**계단 모양이다.** 복제본(D\*=2)을 떠나는 순간 — 첫 체크포인트인 25세대에 이미 —

함께 보고해야 이 그림이 완성된다. 성능은 이 구간 내내 오른다(0.537 → 0.705).

어기는 정책일수록 규칙으로 설명하기도 어렵다.

6개 모두 유의하게 낮았다(−0.08 – −0.18). 학습 상대 BT-v2 에는 조금 강해졌지만(0.50 → 0.56–0.57)
보류 상대 BT-v3 에는 약해져(0.84 → 0.65–0.71) 평균이 떨어졌고, 100 → 200세대에 평균이 0.652 →
0.628 로 내려간 것도 이 때문이다. 평가 교전에서 보정의 크기는 평균 |δ| 0.16–0.20, 실제 지령으로
정규화 0.06 안팎(뱅크 약 11°)에 불과한데도 D\* 는 4 에서 6, 6, 17 로 커졌다. 위반율은 BT-v2 보다
낮다(0.057–0.070 대 0.100).

**게이팅형 — 성능은 순수 학습에 근접, 설명은 절단.** 200세대 점수 0.722 ± 0.047 로 고정 비율
선형 혼합(0.641)보다 높고, 시드 1·2 는 선형 혼합보다 유의하게 높으며(+0.10, +0.12) 순수 학습
정책과는 유의한 차이가 없다(−0.04, −0.02). 시드 0 은 순수 학습보다 유의하게 낮다(−0.11). 그러나
200세대 3개 모두 D\*=17(절단)이다. 게이트가 섞은 두 정책은 D\*=3(학습 정책)과 D\*=4(BT-v2)였다 —
**설명하기 쉬운 두 정책을 섞자 16단계로도 설명되지 않는 정책이 됐다.** 평가 교전에서 게이트 평균은
시드별 0.36 / 0.59 / 0.61, 한 교전 안의 표준편차 0.03, 값의 90% 가 평균 ±0.05 안이다. 게이트는
상황에 따라 규칙과 학습을 골라 쓰지 않고 시드마다 고정 비율 하나를 학습했다 — 비율을 학습으로 정한
선형 혼합이 된 것이다.

**H3 판정.** 혼합 네 방식(선형·감독형·잔차형·게이팅형) 모두 "성능은 높고 D\* 는 낮은" 영역에
오지 못했다. 결론 4 는 네 방식으로 강화된다. 이 확장은 3시드·200세대로 본실험보다 작으므로 수치는
"3시드" 단서와 함께 쓴다. 그림: `results/main_hyb/paper_figs/fig_tradeoff_families.png`(가로 점수,
세로 D\*, 좋은 영역은 오른쪽 아래).

## 7. 논의 재료

* **RQ1 답.** 트레이드오프는 관측되지 않았다(전체 ρ=−0.02, 학습·혼합만 −0.18;
  동등성 검정으로 |ρ| < 0.2). 규칙 모델(D\* 1–5)과 학습 정책(3–17)의 범위가 겹치며,
  가장 강한 정책(s1, 0.785)이 가장 복잡하지만 두 번째(s11, 0.776)는 D\*=3 으로
  BT-v2 보다 단순하다. 공통 상태 D\* 로 재면 부호가 +0.19 로 뒤집히고 방문 범위를
  통제해도 +0.16 으로 남는다. 정직한 진술은 "정책이 실제로 겪은 상황에서 잰 설명 비용은
  성능과 무관하고, 가지 않는 상황까지 물으면 작은 양의 상관(ρ≈0.16–0.19)이 있다"이다.
* **RQ2 답.** 예산이 늘면 성능은 단조 상승, 위반은 감소, 자기 로그 D\* 는 복제본을
  떠나는 순간 한 번 뛰고 평평(계단), 공통 상태 D\* 는 완만히 상승. "학습할수록
  블랙박스가 된다"는 자기가 가는 상황에서는 틀리고, 안 가는 상황까지 물으면 맞다.
  같은 예산·비슷한 점수에서 전술(치고 빠지기 vs 추격 격추)에 따라 D\* 가 3–17 로
  갈리고 군집 안에서는 상관이 없다 — 설명 비용의 진짜 원인은 전술이다.
* **RQ3 답.** 규칙 모델(BT-v3)은 안전을 트리에 명시해 하드덱·과G 위반을 관측상 0 으로 만들고(400교전),
  감독형 혼합(Shield)은 거의 0 으로 줄이되(8,000교전 중 하드덱 30교전) 둘 다 성능을 잃는다. 학습 정책은
  벌점으로 위반을 줄이지만 0 에 못 미친다. 운용 요구가 "위반을 규칙으로 막는 것"이면 규칙 또는 Shield,
  "낮은 기대값"이면 학습이라는 선택 기준이 도출된다. 단 이 0 은 관측된 빈도이지 증명된 보장이 아니고
  (Shield 도 0 이 아니었다), Shield 는 설명 비용도 함께 올린다는 점을 빠뜨리지 말 것.
* **성능 우위의 조건.** 학습 정책이 BT-v2 를 이기는 것은 120 s·HP 규칙에서다.
  규칙을 바꾸면 순위가 바뀐다(R7). 논문의 주장은 "학습이 규칙을 이긴다"가 아니라
  "어느 규칙에서든 성능과 설명 비용이 무관하다"여야 한다.
* **반론 대응.** "설명가능성이란 결국 BT 냐 신경망이냐 아닌가" → 그것은 내재적
  설명가능성이고 이 연구는 행동 수준 설명가능성을 잰다(1절). "BT 는 트리라 유리" →
  복제 MLP(D\*=2) < BT-v2(D\*=4). "D\* 는 트리에 유리한 지표" → F(4)·D\*(0.90)·
  충실도 곡선·공통 상태 D\* 가 같은 결론. "D\* 가 시끄러워 상관이 0 으로 감쇠" →
  신뢰도 0.82, 감쇠 보정 후에도 −0.02(R1). "유의하지 않다 ≠ 없다" → TOST(R2).
  "조건들이 독립이 아니다" → 시드 임의효과 모형·클러스터 부트스트랩(R4). "규칙 모델이
  약한 건 손으로 만들어서" → 같은 예산으로 최적화한 BTO 도 BT-v2 에 진다. "혼합이
  나쁜 건 선형 혼합이라서" → 감독형 혼합도 같은 방향. "학습 계열이 ES 하나" →
  밑바닥 PPO 는 회피로 수렴, 복제 초기화가 알고리즘과 무관한 필요조건. "전술 이름은
  사후 명명" → BIC 군집(R5). "산 모양은 표준편차 안" → 맞다, 그래서 철회하고
  계단으로 보고(R6). "결과는 120 s·HP 규칙의 산물" → 성능 순위는 그렇고, 상관 없음은
  아니다(R7). "성능 = BT-v2 이기기" → 정책 풀 점수 ρ=0.90(R8). "BT 와 RL 에 들인
  노력이 다르다" → `개발노력_기록.md`. "시드 3 결과와 다르다" → 반복 수의 교훈.
* **한계를 먼저 쓴다.** 예시 문장: "본 연구의 규칙 기반 모델과 학습 기반 모델은
  동일 팀이 제한된 예산 내에서 구현한 것이므로 절대적 성능 순위는 일반화할 수
  없다. 본 연구의 주장은 순위가 아니라 관계의 형태에 있다."

## 8. 결론

이 연구는 1대1 기총 도그파이트에서 규칙 기반(행동트리)·학습 기반(신경망)·혼합
정책을 같은 환경·같은 관측·같은 행동공간·같은 지표로 비교하여, "전투성능이 높은
모델은 설명하기 어렵다"는 통념을 측정했다. 학습 시드 20개, 282개 조건, 112,800교전에
통제 조건(상수 최적화 BT, 감독형 혼합, 밑바닥 PPO)과 민감도 분석을 더한 결론은
다섯 가지다.

1. **전투성능과 설명가능성 사이에 트레이드오프는 관측되지 않았다.** 282개 조건의
   점수–D\* 순위상관은 ρ=−0.02(p=0.75), 학습·혼합 정책만 보면 ρ=−0.18(p=0.006)로
   오히려 약한 음이며, 동등성 검정으로 |ρ| < 0.2 가 지지된다. 잡음 감쇠를 보정해도,
   학습 시드를 임의효과로 넣어도, 충실도 임계값을 바꿔도 결과는 같다. 다만 공통 상태
   집합에서 다시 재면 작은 양의 상관(ρ=+0.19, 방문 범위 통제 후 +0.16)이 남는다. 여기서 설명가능성은 "BT 냐 신경망이냐"가 아니라 행동을 규칙으로
   재현하는 데 드는 깊이이며, 규칙 모델(D\* 1–5)과 학습 정책(3–17)의 범위가 겹친다.
   시드 3개에서 보였던 양의 상관(+0.38)은 5·8·20개로 늘리며 0 으로 갔다 —
   트레이드오프를 주장하려면 충분한 반복이 먼저다.
2. **학습 정책은 이 환경의 규칙 아래에서 규칙 모델을 이겼고, 학습할수록 규칙도 더
   잘 지켰다.** 순수 학습 정책의 점수는 0.639(규칙 복제본)에서 0.716 ± 0.051
   (300세대, 시드 20개)로 단조 상승해 최강 규칙 모델(0.671)을 넘었고(17/20), 학습에
   쓰지 않은 상대에도 0.746, 정책 풀 전원 대전에서도 20개 전부 BT-v2 위였다.
   위반율은 같은 기간 0.096 에서 0.050 으로 절반이 됐다. 같은 예산으로 상수를
   최적화한 규칙 모델(BTO)은 BT-v2 를 넘지 못했고, 밑바닥에서 시작한 PPO 는
   진화전략과 마찬가지로 회피로 수렴했다. **단, 이 우위는 120 s 제한·시간종료 시 HP
   비교 규칙에 의존한다** — 제한시간을 240 s 로 늘리거나 시간종료를 무승부로 바꾸면
   BT-v2 가 학습 정책 평균을 앞선다. 반면 성능–설명가능성 무상관은 어느 규칙에서도
   유지된다.
3. **설명 비용을 좌우한 것은 성능이 아니라 규칙 복제본을 떠났는가와 전술이다.**
   자기 로그 D\* 는 복제본(2)을 떠나는 순간 7 로 뛰고 그 뒤 300세대까지 평평하며
   (계단), 공통 상태 D\* 만 예산과 함께 완만히 오른다. 같은 예산·비슷한 점수의
   정책 20개는 '한 번 쏘고 이탈'(16개, D\* 중앙값 5)과 '끝까지 추격'(4개, 8–17)으로
   갈렸고, 이 군집이 D\* 를 유의하게 가르며 군집 안에서는 상관이 없다. 전술 차이는
   적합도를 바꿔도 유지됐다.
4. **혼합은 네 형태 모두 절충점이 아니다.** 지령을 섞은 선형 혼합은 성능에서 순수
   학습 정책을 넘지 못하고 설명가능성에서 어느 쪽보다 나빴다(D\* 14–16). 규칙이
   학습 정책을 감독하는 혼합(Shield)은 하드덱·과G 위반을 거의 0 으로 줄이지만(완전한 0 은 아님) 점수
   (0.543)와 설명가능성(D\* 12)을 함께 내준다. 확장 실험(3시드)의 잔차형은 BT-v2 보다
   강해지지 못한 채 D\* 가 4 에서 6–17 로 늘었고, 게이팅형은 성능은 순수 학습 정책에
   근접했지만(0.722) 게이트가 사실상 고정 비율로 수렴해, D\* 3 과 4 인 두 정책을 섞은
   결과가 17(절단)이었다 — 설명하기 쉬운 두 정책을 섞으면 설명하기 어려운 정책이 된다.
5. **규칙 준수는 '규칙으로 막기'와 '기대값으로 줄이기'의 문제다.** 안전규칙을 트리에 명시하면
   BT-v3 는 하드덱·과G 위반이 관측상 0(400교전), Shield 는 거의 0(8,000교전 중 하드덱 30교전)이
   되지만 성능을 내주고, 학습 정책은 벌점만으로 위반을 크게 줄이면서 성능도 올리지만 0 은 아니다.
   이 0 은 관측된 빈도이며 증명된 보장이 아니다. 규칙을 많이 어기는 정책일수록 규칙으로
   설명하기도 어렵다(D\*–위반율 ρ=0.29). 운용 요구가 어느 쪽인지가 모델 계열의
   선택 기준이 된다.

출발점이었던 상식적 가설(0.0절)과 대조하면, H1(BT 는 설명되지만 약하다)은 설명
쪽만 맞고 성능 열세는 교전 규칙에 따라 뒤집히며, H2(신경망은 강하지만 설명이 안
된다)는 성능 쪽만 맞고 행동 수준 설명가능성은 대부분 BT 와 같은 수준이었고,
H3(혼합은 절충점)은 네 형태 모두 틀렸다. 내재적 의미에서 "BT 는 읽을 수 있고
신경망은 읽을 수 없다"는 여전히 참이지만, 그 차이가 **행동의 설명 비용**으로
이어지지는 않았다는 것이 이 연구의 발견이다.

이 결론은 3자유도 점질량 모델, 1대1 WVR 기총, 고정 규칙 상대 2종(정책 풀 대전으로
보완), BT 복제본에서 출발한 진화전략 학습, 학습 시드 20개, 그리고 사람 대상 이해도
실험을 하지 않았다는 범위 안에서 유효하다. 절대적 성능 순위가 아니라 관계의 형태가
이 연구의 기여이며, 후속 연구는 BVR·다수기·자가대전, 사람의 이해도를 직접 재는 실험
(설계는 `paper/사람평가_프로토콜.md`)으로 확장할 수 있다.

## 9. 개발 이력 — 실패와 수정

심사위원이 가장 신뢰하는 것은 실패를 숨기지 않은 기록이다. 방법 절 또는 부록에
한 문단씩 쓴다. 폐기된 실행은 전부 `results/es_v*` 에 보관돼 있다.

### 9.1 BT 끼리 붙이면 절반이 공중충돌

순수추격만 있는 BT 둘이 정면에서 만나면 서로를 향해 직진하다 60 m 안으로
들어와 교전의 45–53% 가 공중충돌(양측 패)로 끝났다. 이 상태로 학습하면 학습
정책이 배우는 것은 전술이 아니라 "들이받는 상대 피하기"다. 실제 BFM 에서 합류
시 측방 이격 유지는 기본 규칙이므로 세 BT 모두에 `merge_avoidance` 노드를 최우선
으로 넣었다. 충돌은 3–10% 로 떨어졌고 BT-v2 대 BT-v3 교전의 58% 가 격추로 끝난다.

### 9.2 학습 정책이 도망가는 법을 배웠다 (보상 해킹, 2회)

> **쉽게 말하면.** 학습은 적합도(점수표)를 최대로 만드는 행동을 찾을 뿐, 우리가
> 의도한 "잘 싸우기"를 찾는 것이 아니다. 점수표에 "상대 쪽을 향하고 있으면
> 가점" 항목이 있으면, 멀리 도망가서 기수만 상대 쪽으로 두는 것이 격추당할 위험
> 없이 가점을 챙기는 최선이 된다. 아래 두 번의 실패가 정확히 그것이다.

**1차.** 적합도 = 2.0 × 평균 포텐셜(ATA·AA·사거리·에너지) + 승패. 400세대
학습한 정책은 **상대와 6–9 km 떨어져 고도 5–8 km 로 올라가 기수만 상대 쪽으로
둔 채 도망**다녔다. WEZ 0초, 피해 0, 시간종료 100%. 원거리에서도 ATA 가 작고
에너지 우위가 커서 포텐셜만으로 적합도 1.5–2.0 을 챙길 수 있었다. 점수 0.38 은
"무승부 77% × 0.5" 였고 예산을 늘려도 아무것도 변하지 않았다. 조치: 기하 항에
근접 가중(사거리 밖 지수 감쇠), 포텐셜 비중 2.0 → 0.5, 피해·WEZ 비중 확대, 양측
무피해 시간종료 −8. 또 α 커리큘럼(후반 α≥0.9 만 학습)이 α=0.25 정책을 미학습
상태로 남겨 점수 0.14 가 나온 것을 발견하고 매 세대 α 격자를 고정으로 바꿨다.

**2차.** 적합도를 고쳐도 무작위 초기화에서는 **여전히 회피**(100세대 정책 평균
거리 17 km). 교전을 시도하면 BT-v2 에게 격추당해 −30, 도망가면 −9 이므로 ES
탐색이 싸우는 정책을 발견할 확률이 사실상 0 이다 — 희소·고분산 보상에서
진화전략의 알려진 한계. 조치: **BT-v2 행동 복제 초기화**(§3.2). 복제본은
원본과 거의 같게 싸우고, 학습 예산 축은 "복제본에서 얼마나 멀어졌나"가 된다.

### 9.3 ES 가 복제본을 지웠다

복제 초기화 후 기존 ES 갱신(σ 0.05, lr 0.02)을 돌리자 점수가 0.50 → 100세대
0.41 → 200세대 0.00 으로 무너지고 개체군 전체가 같은 적합도로 붕괴했다. 순위
정규화 기울기는 신호가 약해도 크기가 일정하므로 가중치가 매 세대 lr/(σ√pop) ≈
0.06 씩 **무작위 행보**를 하고, 가중치 크기(≈0.3)에 비해 커서 100세대면 복제본이
지워진다. 무작위 초기화 때는 잃을 것이 없어 드러나지 않던 문제. 조치: 갱신
전후의 정책을 같은 시드로 평가해 나빠지면 거부하는 **수용 검사**(대응 비교라
잡음이 작음), 후보당 교전 4 → 8. 10세대 시험에서 수용률 50%, 복제본 유지 확인.

### 9.4 그 밖에

* 하이브리드 뱅크 혼합을 선형 평균에서 원형 평균으로(§3.3).
* 병렬 학습이 느린 원인은 코드가 아니라 CPU(i5-1235U, P코어 2 + E코어 8, 15 W)
  의 전력 제한이었다. 워커를 늘려도 처리량이 2배에서 멈춘다. 대신 시뮬레이터
  핫루프를 numpy 스칼라 호출에서 `math` 연산으로 바꿔 8배(0.2 → 0.02 s/교전)
  빠르게 했다. 결과는 반올림 수준에서 동일함을 참조 궤적으로 확인했다.
* 학습이 됐는지는 셰이핑 적합도가 아니라 **`dfxai.rl.monitor` 의 실제 점수
  곡선**으로 판단한다. 적합도는 1차 시도처럼 오르면서도 아무것도 안 배울 수 있다.

### 9.5 2차 세션: 박사 수준 확장 (9월 14일 밤 – 15일 낮)

8시드 결과가 나온 뒤 "박사 수준 심사에서 무엇을 물을 것인가"를 기준으로 11개
반론을 뽑아 전부 실험으로 답했다. 학습 시드 20개, 상수 최적화 BT 3시드, 밑바닥 PPO
2시드, 감독형 혼합 20개, 25세대 간격 세밀 예산, 규칙 민감도 2종, 정책 풀 전원 대전,
공통 상태 D\*, 신뢰도·동등성·혼합모형·군집 분석(`analysis/robustness.py`), 사람
평가 문항 생성기까지 한 파이프라인(`results/final_pipeline.sh`)으로 7시간에 돌렸다.
이 과정에서 8시드 시점의 '산 모양 D\*' 주장이 세밀 해상도에서 재현되지 않아 철회했고
(6.3절), 학습 정책의 성능 우위가 교전 규칙에 의존한다는 것을 발견했다(6.9절 R7).
두 가지 모두 확장 전에는 논문에 그대로 들어갈 뻔한 주장이었다. 시간 기록은
`개발노력_기록.md` 5절.

## 10. 한계

* 3자유도 점질량 모델: 받음각·옆미끄럼·실속/스핀·무장 탄도를 모사하지 않는다.
  Tacview 재생에서 기체가 항상 속도벡터를 향하는 것은 이 가정 때문이다. 결론은
  이 모델 범위 안에서만 유효하다.
* 1대1 WVR 기총. 상대는 고정 BT 2종이 기본이며 정책 풀 대전으로 보완했지만
  자가대전·BVR·다수기는 후속 연구.
* **성능 순위는 교전 규칙에 의존한다.** 학습 정책의 우위는 120 s·HP 비교 규칙에서
  성립하고, 240 s 나 시간종료=무승부에서는 BT-v2 가 앞선다(6.9절). 성능–설명가능성
  무상관은 규칙과 무관하게 유지되므로 결론 1 은 살아남지만, "학습이 규칙을
  이긴다"는 일반화할 수 없다.
* 학습 정책은 BT-v2 복제본에서 출발했으므로 "규칙과 무관하게 학습한 정책"이
  아니다. 밑바닥 학습(ES 2회, PPO)은 모두 회피로 수렴해 비교 대상이 되지 못했다.
  이는 설계상 선택이며, 그 덕에 "규칙과 같은 행동에서 출발해 갈라진다"는 실험이
  가능했다.
* D\* 의 시드 간 분산이 크다(같은 예산에서 표준편차 4–5, 절단 17 포함). 20시드로
  상관의 신뢰구간은 ±0.2 안에 들어왔지만 D\* 단독으로는 약하므로 F(4)·충실도
  곡선·공통 상태 D\* 를 병기한다. 절단(17)은 R² 0.95 미달이라는 뜻이며 절단 조건의 F(16) 중앙값은
  0.92 다(R9c). 충실도 곡선이 0.95 부근에서 납작해 D\* 는 문턱 근방의 잡음에 민감하다. 자기 로그 D\* 와 공통 상태 D\* 의 상관이 0.27
  에 그치는 것은 두 지표가 다른 것(자기가 가는 상황 vs 모든 상황)을 잰다는 뜻이며,
  어느 쪽이 "설명가능성"에 더 가까운지는 사람 평가로만 답할 수 있다.
* **사람이 정책의 다음 기동을 예측하는 이해도 실험은 설계·문항까지만 준비하고
  실시하지 못했다**(`paper/사람평가_프로토콜.md`, `results/human_study/`). D\* 는
  기능 기반(functionally-grounded) 지표이고 사람 이해도와의 관계는 미검증이다.
* 규칙 모델과 학습 모델을 같은 도구(LLM 코딩 에이전트)가 만들었다. 노력의
  절대량은 `개발노력_기록.md` 에 있고, 절대 성능 순위는 일반화하지 않는다.
